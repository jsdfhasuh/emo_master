# 流程设计：算子右键菜单

从源码启动 Designer，进入 **流程设计**，在节点的标题、节点框或端口上右键，打开节点菜单。右键会只选中当前节点，不会启动、停止检测或改变项目内容。空白画布和连线不打开这个菜单。

| 操作 | 快捷键 | 行为 |
| --- | --- | --- |
| 配置算子… | F2 | 打开该节点已有的配置编辑器；SQLite 写入等专用编辑器仍沿用原入口。 |
| 查看节点结果 | Ctrl+Enter | 显示右侧已有的节点结果面板，沿用当前选择的本次／上一次运行和图片，不增加任务、订阅或另一份图像缓存。未运行时显示真实的无结果状态。 |
| 复制算子 | Ctrl+D | 复制当前普通算子，沿用项目编辑命令。一次操作形成一次撤销记录。 |
| 删除算子 | Delete / Backspace | 删除当前节点及其关联连线，其他节点保持不变。一次操作形成一次撤销记录。 |

复制、删除后可使用现有撤销／重做；保存项目后，新增节点及位置可以重新加载。

按键在流程画布获得焦点时使用；输入框内保留文字编辑。菜单与快捷键共用运行保护，右键菜单只显示按键文字，不重复注册。完整列表和页面工作区行为见 [Designer 快捷键](designer-shortcuts.md)。

## 可用范围

- 检测任务运行中，“配置算子”“复制算子”“删除算子”禁用，“查看节点结果”仍可使用。菜单打开后任务才开始，也会再次检查，避免执行旧菜单的修改动作。
- 工作流 Input／Output 边界节点的配置、复制和删除禁用，继续通过工作流接口管理。
- 子流程、循环节点保留原配置和删除能力；复制仍遵守现有“复制整个工作流”的限制。
- 页面设计工作区使用原页面操作，不显示流程节点菜单。
- 切换工程、工作流、选择或关闭窗口后，旧菜单动作不再有效；Esc 可关闭菜单。
- 已打开的节点结果大图、历史选择及外部 Runtime 的生命周期保持原有规则。

## 启动与验证

已配置 Python 3.10 环境时，无需重新安装依赖。从仓库根目录执行：

```powershell
.\start_designer.cmd
```

保存项目并正常关闭旧 Designer 后再启动；已经打开的窗口不会自动加载新源码。

菜单专项验证：

```powershell
$env:PYTHONUTF8 = '1'
$env:QT_QPA_PLATFORM = 'offscreen'
& "$env:USERPROFILE\.conda\envs\emo_master\python.exe" -m pytest -q tests/designer/test_node_context_menu.py
```

本轮原生 Qt 截图、受测代码身份、失败记录及完整 CI 结果见 [验证报告](testing/node-context-menu-2026-10-06.md)。
