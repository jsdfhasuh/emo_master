# Designer 常用快捷键

保存项目并正常关闭旧 Designer，再从源码启动即可使用本轮接入的快捷键。已经打开的窗口仍运行它启动时加载的源码。

```powershell
.\start_designer.cmd
```

快捷键复用现有项目编辑、Runtime 控制、节点结果和页面预览命令。菜单、工具栏与按键共用动作状态；运行状态、当前工作区和选择变化时更新，执行前再次检查。节点右键菜单显示相同按键，但不重复注册快捷键。

| 快捷键 | 操作 | 使用范围 |
| --- | --- | --- |
| Ctrl+O | 打开项目 | Designer 主窗口；任务运行时禁用。保留未保存修改检查。 |
| Ctrl+S | 保存项目 | 两个工作区；保留已有保存路径和首次保存对话框，先校验并提交页面待输入属性。 |
| Ctrl+Z | 撤销项目编辑 | 两个工作区；任务运行时禁用。输入框有焦点时保留文字撤销。 |
| Ctrl+Shift+Z / Ctrl+Y | 重做项目编辑 | 两个工作区；任务运行时禁用。输入框有焦点时保留原生处理。 |
| Ctrl+D | 复制所选算子 / 组件 | 焦点在当前画布；流程只复制单个普通算子，页面须在编辑态。 |
| Delete / Backspace | 删除选中元素 / 组件 | 焦点在当前画布；流程可删除多选普通节点及连线，边界节点仍受保护。页面须在编辑态。 |
| F2 | 配置所选算子 | 流程画布单节点选择；复用已有专用配置编辑器，任务运行时禁用。 |
| Ctrl+Enter | 查看节点结果 | 流程画布单节点选择；支持主键盘 Enter 与数字键盘 Enter，任务运行时允许只读查看。 |
| F5 | 开始运行 | 流程设计且已加载项目、当前无运行任务；沿用原工程运行入口。 |
| F6 | 停止运行 | 流程设计且存在当前运行 Job；沿用原停止入口。 |
| Ctrl+L | 自动布局 | 流程画布；沿用数据流布局和一次项目事务，任务运行时禁用。 |
| Home | 适应当前画布 | 流程聚焦内容，页面适配编辑区；焦点须在当前画布。 |
| Ctrl+Shift+L | 打开运行日志 | 流程设计；复用原日志面板。 |
| Ctrl+Shift+P | 页面预览 | 页面设计且存在页面；复用当前版本的既有预览入口。 |

画布命令在属性输入框、组合框、数值输入框、文字编辑器、列表或表格获得焦点时让出按键，防止删除节点或复制组件。Ctrl+S 仍可在填写属性时使用；非法待输入内容会显示错误并阻止落盘。点击页面组件后，画布获得焦点，可以直接按 Ctrl+D 或 Delete。模态对话框、打开的弹出菜单和另一 Designer 窗口各自处理键盘输入。

页面复制和删除使用 PageCommands 与统一项目编辑历史；一次操作形成一次撤销记录。正在拖动或处于交互预览时禁用这两个修改动作。流程工作区运行中保护配置、复制、删除、自动布局、流程复制和项目历史；已有命令入口也检查状态，不能通过旧 Delete 回调绕过保护。查看节点结果沿用本次／上一次选择与图片，不增加 Job、订阅或图片缓存。

预览保留当前版本的功能：包含新工作区 chrome 的本机开发版本可打开其既有设计示例窗口；已提交的旧预览入口要求先观看当前工程任务，无可观察任务时在编辑区显示原因。两种入口都不隐式开始检测。窗口关闭后停止本轮动作刷新；按住快捷键不自动重复执行项目命令。

本批接入常用操作。Ctrl+C / Ctrl+V 继续处理文字，节点剪贴板复制粘贴、全量可自定义快捷键及快捷键设置页尚未实现。工作流边界配置、控制流程复制、项目另存和其它编辑操作继续通过已有菜单或按钮使用。

实现集中于 `ui/designer_actions.py`；MainWindow 仅负责构造、状态更新和旧删除入口转接。运行保护共用 `ui/action_state.py`，本轮不增加 Runtime 执行能力。

原始失败、专项、回归、干净候选和原生 Qt 证据见 [验证报告](testing/designer-shortcuts-2026-10-06.md)。本轮结果不改变原运行页面性能目标、Qt 间歇崩溃与现场发布结论。
