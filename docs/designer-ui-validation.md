125% / 150% / 200% 使用测试进程的 `QT_SCALE_FACTOR` 在第一屏 Windows Qt 后端渲染，未改 Windows 全局缩放设置。1366 × 768 是窗口尺寸场景，不是切换物理显示器模式。1920 × 1080 请求会扣除任务栏与边框安全余量，窗口不会强制铺出工作区。
