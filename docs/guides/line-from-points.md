# 两点生成线段

`vision.geometry.line_from_points @ 1.0.0` 把两个已选单点转换为现有 `lineCollection`，可以直接连接 Annotate 的 `lines` 输入。它适用于两个检测区域的中心、圆心、定位点等，不识别业务类别，也不选择目标。

## 连接方式

| 输入 | 内容 |
| --- | --- |
| `startPoints` | 第一个已选点，类型 `list<point2d>`，允许空列表或一个点 |
| `endPoints` | 第二个已选点，类型 `list<point2d>`，允许空列表或一个点 |
| `frame` | 本次图像的 `bbox2d`，声明输出线段所属坐标空间 |

两个点都存在时输出 `lineCount=1` 和一条线段；任一列表为空时输出 `lineCount=0` 和当前 frame 所属的空集合。算子无状态，每次重新生成输出，不会沿用上次连线。上游仍需提供本次空列表，缺少必接输入属于接线错误。

可复用「集合筛选／选择」「检测区域提取」「几何特征取点」生成选中区域中心，然后把两组 `points` 接到本算子。若使用已有工作流提供的中心，直接连接这两个点列表即可。坐标不在同一空间时，先用「点坐标回源／换图像空间」转换；本算子不隐式变换坐标。单端传入多个点、两端重合或来源空间不匹配会明确报错。

## 绘制虚线

把 `lines` 输出接到 Annotate 的 `lines` 输入，并把同次图像及 `frame` 接到 Annotate。配置 `lineStyle="dashed"`、`endpointMarker="dot"`，按页面需求选择 `lineColor` 和 `thickness`。这两项绘制能力已由 Annotate 提供，无需新增图像控件或平台页面专用绘图逻辑。

保存 Annotate 的 `overlay` 后，实时页面与历史页面即可显示同一份标注结果；历史页无需重新寻找当时的两个目标。
