# 页面组件与 SQLite 历史查阅

页面组件库支持自由组合标题、导航、时间、运行结果和本地数据库记录。单页不再显示固定
蓝色页面横栏；多页可以使用工具栏的紧凑页面选择器，或者拖入“页面导航”组件自行布局。

## 可选组件

| 组件 | 用途 | 主要配置 |
| --- | --- | --- |
| 页面标题 | 在自己选择的位置显示页面名或固定标题 | 文字留空跟随页面名称；支持字号、字重、颜色和卡片样式。 |
| 页面导航 | 从页面内容区切换页面 | 自动列出当前工程的页面，页面重命名后同步更新。 |
| 日期时间 | 显示本机当前日期和时间 | 格式为 `yyyy-MM-dd HH:mm:ss`；是当前时间，不是检测记录时间。 |
| SQLite 历史表格 | 查阅已有数据库中的表或视图 | 数据库、表、显示字段、排序字段、方向、每页行数。 |
| SQLite 统计 | 显示已有记录的统计结果 | 数据库、表、统计方式、统计字段、小数位和单位。 |

原有图像、文字、数值、判定指示、集合表格、导航按钮、容器和连接状态组件继续使用。
“集合表格”展示单次流程输出的集合；“SQLite 历史表格”查询已经写入数据库的记录。

## 配置已有数据库

1. 在页面编辑器的组件库中拖入“SQLite 历史表格”。
2. 在属性面板选择本地 `.db` / `.sqlite` / `.sqlite3` 文件，点击“读取表和字段”。
3. 选择已有表或视图，勾选希望展示的字段，设置排序字段和每页行数。
4. 点击“应用修改”，再正常保存工程。修改可以撤销，复制组件会保留查询配置。
5. 打开页面预览，选择“本地数据”，点击组件中的刷新按钮读取记录。

表格可选择一个显示字段进行包含关键词的筛选，也可以清空筛选、翻页及点击列标题排序。
筛选输入按文字处理，例如 `%` 和 `_` 不会被解释成通配符。修改筛选或排序后从第一页查询。
刷新可读取数据库后来新增的数据。页面不会自动修改数据库，也不要求先启动检测流程。

统计组件按整张表或视图计算记录数、求和、平均值、最小值或最大值；统计视图可由现有数据库
定义业务范围。求和与平均值要求非空值为数值类型，避免将文字悄悄算成零。空表的记录数为 0，
其他没有有效值的统计显示空态。统计卡与表格各自配置、独立刷新，表格的临时筛选不会联动统计卡。

## 选中记录查看图片

图像组件可以放在表格右侧、下方或容器内。图片由独立图像组件显示，表格负责查阅记录
和发布当前选择。一个表格可以同时驱动原图、结果图等多个图像组件。

1. 按前面的步骤配置 SQLite 历史表格。数据库已有图片路径字段，例如 `original_image`
   和 `result_image`；字段名由用户决定。
2. 拖入一个“图像”组件，在属性中将图像来源设为“文件路径”。
3. 选择“表格选中行”，选择同页的历史表格，再选择或输入路径字段名。字段不必加入
   表格的显示列；也可以手动输入未展示的字段名。
4. 如果数据库记录保存相对路径，明确设置“图片根目录”：`.` 表示当前工程目录，也可以填写工程内的相对子目录或完整绝对目录。绝对图片路径可以直接使用。
5. 点击“应用修改”并保存工程，在页面预览中选择“本地数据”，刷新表格并点选一行。
6. 需要同时查看结果图时，再添加一个图像组件，选择同一表格的 `result_image` 字段。

图像来源还有“流程结果”和“静态资源”模式；文件路径模式也支持固定路径。这些来源互斥，
切换表单选项后点击“应用修改”才修改草稿。静态资源会随工程管理，路径图片仍是外部文件。

路径字段允许空值，空值会清空图片。文件不存在、字段不是文字、字段已删除或图片无法解码时，
组件显示原因，不继续保留上一条记录的图片。刷新、筛选、排序、翻页、切页会清除选择，
重新选中记录后加载。读取和解码在后台执行，快速切换时只显示最新选择。

联动仅属于当前页面窗口，不修改流程输入或 Runtime 全局变量，也不启动工作流。
两个预览窗口可以各自查不同记录。复制整页或包含表格和图片的容器会重映射内部关联；
只复制图片时继续关联原表格。删除来源表格后可保留未完成草稿，正式校验会报告缺失关联。

### 保存可追溯的历史图片

`Image Saver` 算子的“文件命名”默认“固定名称”，保持原行为；选择“自动唯一命名”后，
在 `outputPath` 或输入 `fileName` 的文件名后添加 UTC 时间和随机标识，保留目录与扩展名。
每次保存得到不同路径，唯一命名不会覆盖已有文件。将该算子输出的 `result.path`
通过现有 SQLite 写入映射保存到图片路径字段，再由页面读取该字段。

修改已有固定路径记录不能找回以前被覆盖的图片；需要从启用唯一命名后的新记录开始保留。

路径图片目前支持 PNG、JPEG、BMP 本地文件，不把 SQLite BLOB 或 HTTP 地址当作图片路径。
单张编码文件上限 8 MiB，源图最多 32 Mi 像素，解码后最多保留 8 MiB，并计入页面显示预算。
JPEG 可在解码时按显示尺寸缩小，PNG/BMP 要求完整解码平面在可用预算内，超限显示原因。
右键“重新加载图片”可以重新
读取同一路径；没有文件监控或自动轮询。

## 本地路径和运行方式

- 路径指向**显示该页面的电脑**。Designer 远程查看 Runtime 结果时，本地 SQLite 组件仍读取
  Designer 所在电脑的文件；不会透过 Runtime 连接访问服务器磁盘。
- 数据库位置支持工程相对路径，例如 `outputs/rtsp-riders/helmet_results.sqlite3`；图片根目录
  填 `.` 时，数据库中的 `outputs/...` 图片路径也按当前工程目录解析。搬动完整工程目录后，
  重新打开工程即可跟随新目录，不需要把路径改成本机盘符。解析后的完整路径只用于读取，
  不写回工程配置。未打开工程、没有明确工程目录时会报告原因，不使用程序工作目录猜测。
- SQLite 写入算子的 `fileReferencePathMode=project_relative` 可把新记录的文件引用保存为相对
  工程目录的路径（默认仍为 `absolute`）。页面不会自动改写旧记录中的绝对路径；搬迁历史库时
  需要先备份并明确迁移已有路径。
- 数据库文件不加入工程资源清单，也不会随工程上传或打包。在另一台电脑显示页面时，需要
  在那台电脑准备已有数据库并配置正确路径。
- 数据库以只读连接打开，不创建文件、表或索引，不执行新增、修改、删除记录。
- 设计画布和“示例数据”/模拟状态只显示组件占位。读取表结构由属性面板明确触发；查实际记录
  使用“本地数据”预览或正常 Runtime 页面。
- 查询在后台执行，每次读取一页，最多 100 行、32 列。BLOB 显示大小说明，长文本截断显示。
  文件不存在、表字段改变、锁定或查询失败时显示原因，可修正后刷新。
- 单次查询有时间限制；正常大表建议在数据库中为常用排序与筛选设置适合业务的索引。组件本身
  不修改数据库结构。查询期间的数据库更新在下一次刷新中可见，跨页查阅不承诺固定历史快照。

新建工程使用 `schemaVersion: "2.8"`，页面内部版本为 `1.1`，新页面默认响应式排列；
旧工程的页面 `1.0` 保留原有网格解释，不会因打开而自动改写。新增字段详见
[工程格式规范](../project-json-spec.md)。包含新增组件的工程需要本次功能对应的 Designer / Runtime
源码或重新构建的程序；已经安装的旧 EXE 不会随源码修改自动更新。
