# Designer 页面空间、终端预览与空白块

用户确认日期：2026-11-02。Designer 基线 `46af63de553f0cf60f64ce0b2f37440362a55da2`；Web 基线 `b1ca6d386e8bb5cf4d21609e52f09acd0803126b`。

## 已确认目标

- 跟随窗口作为默认模式，页面四周8逻辑像素并居中；手动缩放/平移后保持视图，适应画布/Home恢复自动适配；拖拽时延后适配。
- 页面顶部64像素预留改12；按后续截图确认，工具区/属性面板复用流程设计的浮动面板交互，默认在画布左上/右上，收起后保留可拖动标题条，展开仍为浮动面板。入口不放到底部预览工具栏，不参与页面内容布局。
- 属性面板顶部显示当前控件的“所属组”和“选择父组”；嵌套容器逐级上选，根组件提供“所属页面”和“选择页面”。复用现有选择和待应用输入处理，不增加工程历史或重置画布；组名过长省略显示，悬停可看全名。
- 固定终端预览设置逻辑宽高，预设360×640、768×1024、1280×720、1920×1080；尺寸指页面视口，画布缩放不改变排版宽高。预览状态不写工程/历史。
- 默认“跟随窗口”编辑时，页面按响应式宽度排版，并让画布容纳完整内容；“适应画布”按整页边界等比缩放居中，取消整页内部滚动条。用户放大后通过画布平移查看。固定终端预览及桌面运行页面继续按真实溢出显示浮动滚动条，不占内容宽高；真实布局与候选测量共用尺寸基准，编辑提示不得制造溢出。
- 后续确认的持久扩展：第一项标题继续向上拖动时，标题实际落到原边界上方，扩展后的画布范围保留，保存重开一致；使用 `canvasTop` 与根组件 `canvasOffsetY`，保持响应式宽度及流占位。顶边持续拖动会继续上移查看；松手一次历史，Esc恢复视图和模型；固定终端不改可视宽高，扩展增加滚动内容。取消临时“放在页面最前”文字辅助条，保留橙色虚线原位置、绿色实线落点和受影响组件的灰色轮廓。
- 边缘尺寸调整：响应式页面单选组件后，四边和四角显示小手柄，整段边缘可命中对应的水平、垂直或对角尺寸光标，并给出悬停提示。左右边只改宽度、上下边只改高度、角点同时修改两者；复用现有吸附、候选布局、一次提交、Esc和撤销。命中范围兼顾缩放及标题拖动区域，不遮住内部移动入口；组件位置仍遵循响应式排列，多选不增加整体拉伸行为。
  手动改宽时如父组为并排/换行且开启等宽，将该组退出强制等宽，与组件尺寸同一次提交；兄弟组件字段保持不变，按原有规则分配剩余空间。只改高时解除该组件的行高拉伸，保留组等宽及组件宽度。预览显示求解后的真实尺寸，内容自然高度限制明确提示；松手、Esc与撤销同步处理尺寸及必要的布局规则，保存重开保留结果。
- 空白块 `spacer` 默认24×24，固定/弹性，编辑有虚线提示、预览和运行透明；复用选择、拖动、复制删除、编组和撤销保存。
- 弹性按响应式父布局主轴分剩余空间；竖排撑高、并排撑宽、换行只撑所在行，多块按权重；不足时保留最低占位，不压缩正常内容。旧grid支持固定占位并说明弹性条件。
- 共享模型的空白块基于SDK1.2.0；本次持久画布字段推进至SDK1.3.0，Qt、Web包校验及渲染同步，契约通过脚本生成。工程保持2.9/页面1.2。

## 实施顺序与边界

1. 页面空间、终端宽高与视图状态。
2. 浮动滚动条及网格/响应式测量，保护缩放尺寸拖动修复。
3. 空白块共享模型、纯布局求解、Qt渲染和编辑属性。
4. Web包与透明渲染、SDK和规范、针对性验证及Dot人工验收指引。

沿用现有Designer与Web分支，不合并两个开发分支或主分支，不部署。旧grid转响应式和旧头盔页面Ctrl多选不在本轮范围。现场工程只读；验收使用临时副本/最新格式临时工程，不访问设备。

## 完成标准

默认编辑的空/短/长页面均无整页内部滚动条，“适应画布”能看到整页；固定终端及独立运行页面按溢出显示浮动条且宽度稳定。普通属性修改/刷新不自动缩放，窗口变化与显式适配按现有规则处理；固定视口尺寸不被DPI预算悄悄改写；75/100/150%画布缩放下拖动、吸附、取消、撤销与保存重开正常。空白块两端固定/弹性/权重/嵌套一致，旧grid固定占位正常。
