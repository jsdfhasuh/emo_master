## 后续修正：面板收起后保留画布顶部标题条

用户截图确认页面面板应与流程设计采用相同浮动交互。原实现虽复用 `FloatingPanel`，但页面启用了 `externalToggle`，收起时隐藏整个面板，再通过底部预览工具栏按钮展开；入口位置不符合该要求。

在 Designer `8df8599fc026c424a49e87cc53fb45f6b371f16f` 后的工作区修改中，删除这项页面专用分支和底部重复入口，恢复共享组件原有的收起行为。工具区/属性面板默认分别位于画布左上/右上，收起保留可拖动标题条；保留本机位置记忆、页面12px内边距以及独立的底部终端预览控件。流程面板原有行为不变。

扩展已有视口回归，检查收起可见、默认顶边/侧边位置、真实子控件命中、点击展开和关闭，以及页面几何、显示变换、payload和历史不变。修前该回归在“收起后仍可见”断言失败，修后页面视口、浮动工作区、组件库以及流程运行面板/工具区相关测试共 **55 passed**；定向 Ruff、`git diff --check` 通过。本机证据为 `build/panel-header-before.xml`、`build/panel-header-after.xml`，Qt离屏渲染截图为 `build/panel-header-collapsed.png`。测试和截图均使用临时本机设置及模拟客户端，不操作正在使用的 Designer 窗口。此次结果不替代真实桌面鼠标与Windows显示缩放验收，前文历史测试结果保持原记录。

## 后续修正：属性面板隐藏字段不再留下空带

同一工作区继续修正用户提供的“页面导航”属性面板截图问题。Qt 5 的 `QFormLayout` 在整行控件隐藏后仍保留行间距：内容分组内的多条隐藏属性、位置分组内的旧网格属性，以及响应式表单内隐藏的容器排列属性累加，产生大段留白并增加滚动距离。

分组内已有字段包装改用顶部对齐的纵向布局；外层隐藏分组不保留行间距；响应式排列设置与组件尺寸各自整体显示/隐藏。保持现有控件实例、属性读写和底部应用按钮。在相同字体、面板尺寸的Qt离屏复现中，“宽度方式”标签由面板内y=422移至y=230；滚动范围由790减少至586。

新增常规/小窗口回归，在普通组件、容器、页面属性间切换，检查首个可见字段贴顶、分组无空带、无横向溢出及payload/历史不变。修前 **2 failed**，修后页面外观、浮动工作区、待应用属性、响应式编辑、画布视口相关测试共 **73 passed**；定向 Ruff和`git diff --check`通过。证据在本机 `build/property-spacing-before.xml`、`build/property-spacing-after.xml`，前后离屏截图为 `build/property-spacing-before.png`、`build/property-spacing-after.png`。未执行真实桌面鼠标复测，不替代Dot验收。
