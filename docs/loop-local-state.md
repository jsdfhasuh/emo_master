# 多视频流程中的局部循环索引

## 何时用局部状态，何时用全局变量

While v2 已支持具名状态端口：循环体的同名输出成为下一轮的输入，退出后返回最终状态。
人物索引、车辆候选索引这类只服务于当前循环调用的数值，可以用这条现有机制，
不必每轮通过全局变量读写节点访问 Runtime SQLite。

全局变量仍适用于跨流程共享、在线管理端修改、原子计数和持久化。不能把这类变量
自动替换为局部值。本次不改变变量生命周期、CAS revision、SQLite FULL 提交、
全局布尔 While 条件或下次调用时读取参数绑定的语义；没有新增内存变量缓存。

## 接线方式

1. 循环体增加 `index: integer` 输入与同名输出；While 节点的状态端口与它们一致。
2. 初始值使用“整数加法”，左、右默认值都为 0，输出连接 While 的 `index`。
3. 循环体的 `input.index` 连接集合选择的 `index` 输入，模式选“按索引”。
4. 同一个 `input.index` 连接“整数加法”的 `left`，`rightValue=1`。
5. 加法输出连到 `output.index`，并与目标数量比较，产生下一轮继续条件。
6. 需要保存文件名时，把**当前输入 index**传给保存子流程，不能误用已加一的输出。

每次进入循环都会由初始输入重新建立状态。嵌套循环、连续处理下一视频和另一个 Job
不会继承上一次局部索引；取消后重新运行也是新的调用。

## 两个通用能力

- `vision.collection.select` 新增可选 `index: integer` 输入。只在 `mode=index` 使用，
  输入优先于固定的 `params.index`；未连接时保持原行为。负数、布尔、浮点、文本、
  null 不会自动转换。越界仍遵循原 `onOutOfRange` 规则，空集合行为不变。
  Designer 仅在索引模式（或动态模式）显示该输入；切到其他模式后，已有连线保留并
  标为当前不适用，不会悄悄删除。Runtime 的完整端口声明不随显示模式删减。
- `vision.math.integer_add` 是纯计算算子，无数据库或跨调用状态。可选 `left/right`
  输入优先于 `leftValue/rightValue` 默认参数，结果是精确的 64 位有符号整数。
  不经浮点数转换，溢出报错。两侧不连接且默认值为 0 时可直接提供整数初始值。

平台目前锁定精确算子版本。集合选择的兼容可选端口扩展保留原 `1.1.0` 标识，
避免要求用户迁移原工程；没有放松依赖校验。新整数加法为 `1.0.0`。
包含新输入/算子的新工程仍需要本轮源码或随后重新构建的程序；旧安装版不会热更新。

新建工程仍按工程规范使用完整 **schema 2.7**，通过 `WorkflowStore().toPayload()`、
`ProjectDocument`、`saveProject()` 创建，并保存重读、编译。不能只改版本号。
