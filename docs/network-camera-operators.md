# RTSP 摄像头读取与海康摄像头发声

这两个内置算子使用 Runtime 所在电脑的网络，不会在打开工程、编辑参数或保存工程时连接设备。
现有工业相机、设备管理和 TCP/PLC 算子不变；本次不新增受管摄像头设备类型。

## RTSP 摄像头读取

- 算子 ID：`vision.io.rtsp_camera`，分类：预处理。
- 每执行一次，新建 RTSP 连接、读取一张画面并释放连接。下游耗时不会让这个算子持续积压旧帧。
- 输出 `image` 为标准 OpenCV BGR 图像，选择灰度模式时为单通道图像；`frame` 为标准 1.1 图像坐标系。
  可直接接 YOLO、裁剪、图片保存等现有算子，也使用现有节点结果图片链路。
- `capturedAt` 是 Runtime 收到画面时的 Unix 秒时间戳，不是摄像头硬件曝光时间戳。

| 参数 | 说明 |
| --- | --- |
| `rtspUrl` | 不含账号密码的 RTSP 地址，支持 `rtsp://` / `rtsps://`；后者仍取决于设备和 FFmpeg 后端能力 |
| `username` | 默认 `admin`；无认证流可留空 |
| `password` | 密码输入框，默认空 |
| `passwordEnv` | 可选的 Runtime 进程环境变量名；非空时优先于 `password`，变量缺失时明确报错 |
| `openTimeoutMs` | 连接超时，默认 5000 ms，范围 100～60000 |
| `readTimeoutMs` | 单次读帧超时，默认 5000 ms，范围 100～60000 |
| `colorMode` | `color` 或 `grayscale`，默认彩色 |

海康常见地址示例：`rtsp://<摄像头地址>:554/Streaming/Channels/101`（主码流）或
`rtsp://<摄像头地址>:554/Streaming/Channels/102`（子码流）。端口、路径、编码以设备配置为准。
账号和密码分别填写，不要拼进地址；特殊字符由算子编码。

算子使用仓库已有的 OpenCV FFmpeg 后端，不启动外部播放器、不修改进程级 FFmpeg 环境变量。
默认打开和读取阶段分别最多等待约 5 秒；取消会在阻塞调用返回后生效，连接随后释放。
失败结束本次调用，不在内部无限重连；之后再次执行会重新连接。
它是流程中的按需取图算子，不是常驻预览、录像或逐帧无损视频处理器。持续检测可由现有生产周期或循环调度，
每次重连有开销，不保证视频帧率和设备曝光时刻同步。

## 摄像头发声（海康）

- 算子 ID：`communication.camera.hikvision_audio`，分类：通讯。
- 使用海康 H8 固件的 ISAPI AudioAlarm 接口、HTTP Digest 认证。
- 播放摄像头内置音频或已经上传到设备的自定义音频；不播放电脑本地扬声器。
- 不包含音频上传、音频转码、实时对讲或任意文字转语音。

| 参数 | 说明 |
| --- | --- |
| `cameraUrl` | 摄像头 HTTP(S) 根地址，如 `http://<摄像头地址>`，可带端口；不含路径或凭据 |
| `username` / `password` / `passwordEnv` | 与读取算子的认证字段相同；发声需要用户名及有效密码 |
| `audioSource` | `builtin` 内置音频，或 `custom` 已上传音频 |
| `audioId` | 内置音频 ID，默认 12（链接聊天中的 H8 设备为提示音）；执行前核对设备能力列表 |
| `customAudioId` | 自定义槽位 1～3；H8 播放 ID 映射为 13～15，必须已上传到对应槽位 |
| `maxVolume` | 接受的最大设备音量，默认 30，范围 1～100；不是设置设备音量 |
| `maxAlarmTimes` | 接受的最大设备播放次数，默认 1，范围 1～50；不是设置设备播放次数 |
| `timeoutMs` | 每个 HTTP 请求的网络超时，默认 5000 ms，范围 100～60000 |

输入 `trigger` 为可选布尔值：未连接或为 `true` 时触发；`false` 时完全不访问设备，输出
`triggered=false`，其余数值输出为 0。可把 NG 判断结果接到 `trigger`。
它不是上升沿检测器：每一次执行且 `trigger=true` 都会发出新的播放请求。

播放前只读查询声音能力、所选音频和当前音量/次数，自定义音频还会查询已上传槽位。
随后仅向 `/ISAPI/Event/triggers/notifications/AudioAlarm/<ID>/test?format=json`
发送一次有效的空请求体 `PUT`。Digest 的一次 401 认证挑战不算重复播放，错误密码不会无限重试。
不写全局声音配置，不临时修改后再恢复音量，也不绕过正常的调试确认。

**一次请求不等于只响一次。** 实际音量和重复次数由摄像头当前配置决定。
链接聊天中此前读到的是音量 100、次数 5，本轮没有重新查询实机，当前值可能变化。
如果现场仍为该设置，默认 30/1 限制会拒绝播放。应先明确调整摄像头配置，或者在接受当前现场效果后
把算子的允许上限设置为 100/5；调高允许上限本身不会修改设备。

成功输出 `triggered=true`、实际 `audioId`、读取到的 `volume` 和 `alarmTimes`。
成功表示设备确认接收触发，不代表已监听确认实际出声或播放结束。
播放超时、断连、HTTP 5xx 或缺少明确成功回执时返回 `E_CAMERA_AUDIO_UNKNOWN`，不自动重发。
发送前取消不会补发；已发送的声音不能通过取消撤销。错误密码、空槽位、超出允许上限会明确报错。
其他品牌、其他海康固件尤其是自定义音频映射，不在已核对的协议范围内。

## Designer、凭据与验收

两个算子均进入内置目录和普通参数编辑器，单节点调试走已有的显式确认机制；不会被纯算子自动试算或
工作流调试自动执行。正常 Runtime 工作流执行不额外弹窗。

密码框的遮蔽只是显示保护，**不是工程文件加密**。直接填写的密码会作为普通参数保存到工程中。
不希望密码进入工程时，填写 `passwordEnv`，并在启动 Runtime 的进程环境中提供该变量；
远程 Runtime 不读取 Designer 电脑的环境变量。错误消息和输出不回显密码，RTSP `frame.coordinateSpace.sourceId`
也不携带认证信息或原始查询串；用查询参数区分通道时保留查询串摘要，避免不同通道混用坐标系。
共享工程和收集第三方后端原始日志时仍应检查凭据。

源码变更需重启使用该源码的 Designer/Runtime 才能加载；已打包 EXE 需要重新构建，源码修改不会热更新 EXE。

本次验证使用 Python 3.10、PySide2、临时 2.7 工程、模拟帧和本机回环 HTTP 服务：

- 插件严格注册、参数与 manifest 一致性、中文参数标题。
- RTSP 成功/失败/取消释放、后续重连、密码编码；本机 OpenCV FFmpeg 实际打开临时视频验证超时选项。
- Digest 认证、内置/自定义音频、条件跳过、取消不补发、未知回执不重试。
- Designer 原生 Qt offscreen 打开入口、参数显示、遮蔽密码、编辑保存后重读。
- 原生 WorkflowRunner 传图至下游、重复运行，以及独立进程单节点发声调试的确认和结果返回。

没有连接真实 RTSP 摄像头，没有现场发声、修改摄像头配置或上传音频；也没有执行冻结包或真实桌面人工验收。
本机视频解码不等于真实 RTSP 传输、编解码或长期运行验收。
