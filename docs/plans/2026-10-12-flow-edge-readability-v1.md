## 1 目标与范围

让用户在较密流程中快速回答：当前节点从哪里取数据、输出去了哪里、准备操作的是哪一条连接。保持全部真实连接可达，不通过隐藏错误、移动节点或改变工程数据制造改善。

本轮包括：普通连线弱化，节点/多选节点/端口/单边的直接关联聚焦，同源实际重合线段去重，共享干线和交叉歧义的支路菜单，精确选择/删除/撤销，以及状态恢复和独立 dot 验收。

不包括：总览缩放摘要、递归全链或跨工作流追踪、跨信号数据总线、新转接节点、工程 schema/RPC/Runtime 执行语义变更、打包发布、生产设备或部署。

### 正式交付前置

原工作区在本轮开始前已有未提交的相关画布改动。为了在正式远端版本独立运行，本次提交一并包含这些紧邻前置：

- `flow_layout.py` 的端口感知显式布局与对应测试。只有用户主动布局才移动节点，不在查看/聚焦时布局。
- `flow_routing.py` 的通道和分片搜索支持；Scene 的拖动局部路由、松开后合作式优化与取消快照。
- `designer_graphics_view.py` 的视图导航边界；小图/空白区域在多个缩放下可真实平移，边界变化不移动节点。
- 窄边命中及选中渲染修复与相关回归。

这不是仅有灰色线条的色值变更，正式前后对照需注明上述前置。此前未提交的工作流导航回调、侧栏导航、页面设计、Runtime、YOLO 和私有工程不混入提交。Scene 保留正式基线的一参数工作流打开回调及事件返回后切换场景的行为。

## 3 显示与交互契约

| 状态 | 显示与恢复 |
| --- | --- |
| 无选择 | 所有真实边可见且可命中；普通线中性灰 1.6 |
| 单选/多选节点 | 突出直接输入输出边/其并集，不递归追踪；关联高亮不等于选中 |
| 端口 hover | 仅对应端口连接临时聚焦，离开恢复原选择；按下仍启动拖线 |
| 边 hover | 临时突出准确支路和端点，不改选择、dirty 或撤销栈 |
| 精确边选中 | 琥珀色 3.2、完整源到目标路径、端点环和方向；兄弟支路不被误标为选中 |
| 无关边 | 浅灰 1.2，仍可命中；不以全局 opacity 隐藏错误 |
| 关联聚焦 | 蓝色 2.2；不能覆盖已选边的明确标记 |
| 受阻 | 保留橙色虚线及原因，选择时不洗掉错误形态 |
| 共享/交叉歧义 | 菜单显示源、目标、端口和可区分 ID；hover 仅预览，点击才选择 |
| 清除/切换 | 空白点击/平移清除；Esc 优先取消拖线/菜单；切换工作流、删除和重开清除旧状态 |

### 公共段与命中

1. 源身份为当前工作流内 `(fromNodeId, fromPort)`，边身份保持四元组；工作流切换清空缓存。
2. 只归并同源、共线、实际重合且诊断相容的片段；不同输出/不同信号和相近并行线不合并。
3. 公共段只画一次，真实分叉有连接点；普通交叉不画连接点。选中公共路径不把兄弟支路变成选中。
4. 公共段从独立边命中层扣除，交由公共命中项消歧。辅助线项不是额外可选择/删除实体，也不占据大块空白。
5. 菜单取消恢复原选择，Delete/Backspace 不能借菜单批量删边；选定真实边后复用既有命令和撤销。
6. 拓扑/路由变化重建派生缓存并使旧菜单回调失效；hover/选择只解析样式，不调用路由器。
7. 拖动维持局部更新，松开后分片优化；新编辑/删除/切换取消旧快照，不回写失效对象。

### 不变量

- 只查看、聚焦、hover、开关菜单不改变图、节点位置、dirty、保存数据或撤销栈。
- 保留输入端口唯一连接和类型校验，不改变执行顺序和字段映射。
- 删除一条支路只删除该真实边；撤销/重做准确恢复端口、路径和公共段。
- 保存重开保留边与坐标；聚焦/菜单是瞬态状态，不写入工程。
- 旧工程无需迁移。源码修改不更新已运行进程或旧安装包。

## 5 测试与门槛

- 纯函数：邻接并集、优先级恢复、完全/部分重合、反向段、不同信号、拐角、分叉、受阻和退化段、确定性。
- 场景：菜单预览不改选择，精确 edge key，删除/撤销/重做，输入替换、节点删除、工程切换，旧菜单和旧快照失效。
- 不变量：查看前后图/坐标不变，dirty/undo 不增加；聚焦触发路由次数为 0。
- 原生绘制：实际像素与事件，端点、选中边、共享段、交叉、中文长标题；不能只检查 pen 属性。
- 相关回归包括连线选择、路由通道、布局、Scene 交互、拖动响应、视图导航、保存加载和纯算子夹具运行。最后执行 `scripts/ci_check.py`。
- 多缩放真实平移检查应验证视口位移，不能只检查 `isPanning` 状态；节点/边不变。
- 同工程、同坐标、同窗口、同系统 DPI、同画布 zoom 比较前后，不主动自动布局。
- 真实获准工程与固定 100 节点/300 边显示压力图各测至少 30 次聚焦/选择。参考桌面聚焦反馈 P95 目标不超过 100ms；新增显示层的局部拖动 P95 相比同机基线恶化不超过 20%。完整路由耗时与网络/VNC 传输延迟单列。
- dot 各做三次找输入来源、找输出目标、共享干线选支路并删除撤销，记录正确性、步骤、时间和误选；首次发现与熟练后分列，不以小样本宣称统计改善。
- DPI 至少完整执行参考桌面 100%/150%；Windows 100/125/150/200% 单列。不能以缩放图片代替系统 DPI。
- 重叠测试组 PASS 不相加。失败、基线失败、SKIP、UNSUPPORTED、NOT_RUN 分列；不削弱断言或覆盖用户工程制造通过。
