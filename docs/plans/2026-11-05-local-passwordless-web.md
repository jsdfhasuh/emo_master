# 首次免建账号的本机 Web 管理员模式

作者：dot。基线：PR #11 的 `8fc3433973a865823e1b596dadf3dc8bc7f04fd1`。

## 用户目标与权限决定

用户希望首次启动也无需创建账号，在原分支实施并推送，再继续验收。经说明管理员可编辑、发布并启停全部已登记 Runtime 后，用户明确选择“使用管理员权限”。因此本机模式不是只读，也不把已有远端 Runtime 静默排除。

## 最小实施计划

1. 增加默认关闭的 `serve --local-no-auth`；仅字面 loopback、固定端口，不支持代理/隧道、额外允许来源或 preview 混用。
2. 在现有 SQLite 会话机制中增加独立本机身份与会话类型。稳定身份没有密码、不创建普通账号；会话保留随机 token/CSRF、过期和注销，绑定本次服务实例。普通账号与权限逻辑保持原有语义。
3. 统一保护 HTTP 和 WebSocket 的真实 peer、精确 Host/Origin、重复头与转发头。签发会话走单独 POST，要求同源 Origin 和显式请求头；GET 不签发会话。CLI 禁用 uvicorn 代理头处理。
4. 首次浏览器打开直接进入；退出、到期或重启后旧会话不自动复活，明确重新进入后恢复同身份草稿与待确认记录，不重放业务请求。运行页和编辑器持续说明管理员权限和停用方法。
5. 验证首启零账号、管理员编辑保存、稳定身份、CSRF、TTL/退出/重启/关闭模式、HTTP/WS边界以及普通密码模式回归；补真实 Chromium + 合成 Runtime 的功能验收，纳入双平台 Web CI。
6. 在原 PR 分支正常提交、推送；由 dot 在 PR 评论说明修改内容、设计逻辑、测试结果和未执行层级。不得合并、部署或访问现场设备。

## 明确边界

- 只有本机入口，不意味着只有当前 OS 用户能访问。其他本机用户或进程也能成为本机管理员；不适合不可信共享电脑。
- 管理员仍可控制所有已登记远端 Runtime。打开页面、保存草稿与预览不会自行启动检测；设备操作仍由用户显式发起。
- 同机反向代理可隐藏远程来源，应用无法证明它没有伪造请求。禁止反代/隧道暴露，不能用检测到转发头就拒绝来声称已解决所有代理暴露。
- 本模式是用户要求的产品功能，测试仅验证该功能，不用它绕过工具的既有安全登录限制；本机模式测试通过不等于原密码登录的人工验收通过。
- 源码/合成自动测试、真实浏览器、实际软件 Runtime、原生 Windows/Qt 与现场真实设备分别报告。未运行的层级不得记为通过。
