# EmoMaster Qt Widgets 与 QSS 规范

基线更新：2026-09-10。适用于 PySide2 / Qt5 Designer，当前实现与验收见 [验证记录](designer-ui-validation.md)。

## 设计原则

- 保留左侧工具区、中央画布、右侧检查区的工程工作台，不使用宣传式入口页或嵌套卡片。
- 白色、中性灰为背景，蓝色用于交互、焦点和主要动作；红、绿、黄色用于状态和警告。
- 普通圆角为 4–6 个逻辑像素，最大 8；边框、间距、焦点及禁用状态统一。
- 正文字体默认 `Microsoft YaHei UI` 10.5pt，不随窗口宽度改变；不可用时由内部字体接口选择可用中文无衬线字体。
- 控件与画布使用同一字体接口。标题可加粗，但必须按加粗后的字体度量预留尺寸。

## 主题入口

| 文件 | 职责 |
| --- | --- |
| `ui/theme.py` | 字体回退、Fusion 基础风格、调色板与屏幕尺寸约束 |
| `ui/styles/app.qss` | 控件状态、背景、边框、间距和对象名样式 |
| `ui/icon_map.py` / `ui/_lucide_data.py` | 带提示的离线 Lucide 图标及许可证 |
| `ui/control_icons_rc.py` | 打包进 Python 模块的 Qt 控件箭头/勾选资源 |
| `ui/widgets.py` | 可省略文本、换行文本、等比预览、纯标签栏和滚动容器 |
| `ui/node_geometry.py` | 统一节点度量与按实际尺寸的自动排列 |
| `operator_editors/builtin_layout.py` | 限定内置编辑器的展示层重排 |

以上路径均相对于 `src/emo_master/apps/designer`。应用在创建窗口前统一调用 `applyDesignerStyle()`，禁止在每次调整窗口大小时反复设置 QApplication 的字体或样式。

## 色板与间距

```text
background = #f5f6f8
surface = #ffffff
text = #20242b
muted = #626b78
border = #d8dce3
accent = #2563eb
accentHover = #1d4ed8
selection = #edf3ff

spacing = 4 / 8 / 12 / 16 logical pixels
radius = 4 / 6 / 8 logical pixels
```

菜单栏与工具栏均保持浅色。一个工作区只有明确的主要动作使用实色强调背景；不要恢复大面积橙色、深色菜单或渐变。

## 主窗口与画布

- 工具栏和菜单复用 QAction，图标来自程序打包资源，不使用特殊字符充当工具图标，不增加在线加载。
- 左栏默认折叠为 36 个逻辑像素；最小、最大宽度与 splitter 恢复必须一致，展开宽度保留用户拖动结果。
- 工作流只显示标签栏，不保留空白页面。标签使用加粗字体度量来稳定宽度；超长标签允许省略并提供完整提示，新增按钮不参与标签滚动。
- 节点宽度限制为 260–420，标题和左右端口分列度量，高度按端口数增加。端口定位、连线、命中、内容边界和自动布局必须共享几何结果。
- 读取项目不得为了适配新尺寸改写节点坐标；只有显式自动布局重新排列。
- 首次定位应在视口布局稳定后执行，自动缩放下限 85%。手动适应整图可以更小；缩放显示必须读取实际 view transform。
- 新增节点、普通窗口调整和跨屏移动不重置用户缩放。

## 参数、详情与预览

- 常规文字完整显示，说明可换行。只有极长名称和路径允许省略，并提供完整提示。
- 使用字体度量、sizeHint 和布局约束计算尺寸，不以固定高度容纳任意文字。
- 详情与参数区可以滚动，预览保留原图并按可用空间等比缩放，底部操作不放入可能滚出视口的表单。
- 编辑器重排必须同时匹配内置算子 ID 与根控件名；保留 `.ui` 控件名称、参数键和值、Controller 绑定和预览行为。
- 第三方编辑器不强制重排；原生文件选择器保留系统外观。

## 验证要求

- QSS 字符串检查不能替代真实 Qt 几何和像素渲染测试。
- 覆盖中文混排、长路径、双侧多端口、长参数、多工作流、选中状态、窗口缩放、工具栏溢出和预览比例。
- Windows Qt 验证 100%、125%、150%、200% 与可用屏幕之间的移动，区分进程缩放、实际物理屏幕和现有实例人工验收。
- 所有自动测试使用隔离设置和模拟运行时，不自动连接相机；发布前另做冻结资源、真实屏幕和硬件验收。
- 保留前后截图、测试日志和源项目只读证明，并明确列出未验证项。
