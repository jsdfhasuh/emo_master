## 审查结论

### 已修复的正常路径缺陷

**P2：诊断导航掩盖具体校验原因。** 缺少输入图片时，Runtime 返回 `input file not found` 以及流程、节点、参数位置；Dot 新增的 `configurationDiagnostics()` 对非设备问题使用固定的泛化文本，`_notify()` 又用它覆盖主提示，用户需要展开详细信息才知道实际原因。

- 证据层次：源码审查、内嵌 Runtime 与 loopback RPC 测试；原远端 `3c8a56ff` 上也能复现。远端复现只用于确定来源，不作为接受缺陷的理由。
- 最小修复：通用诊断保留 issue 的原始 message，同时继续提供详细信息和“定位节点并配置”；设备专用说明不变。
- 回归断言仍要求具体错误可见、节点可定位、修正后重新校验成功、草稿和磁盘未被意外覆盖、未启动 Job 或发布工程。

### 合并与测试契约校正

- `main_window.py` 同时保留本地文件关联和远端在线副本引用；移除自动合并形成的重复 `_runtimeProjectReference()`，运行和图片观察使用已发布副本的 `sourcePath`。
