## 2. 改了什么

| 项目 | 当前实现 |
| --- | --- |
| 去除专用层 | 移除 `production.stations`、工位配置表单、工位入口/页面/保护变量归属、专用首拍确认 RPC 字段和配套准入；不是换名保留同一层。 |
| 普通流程并行 | Designer 和操作端选取已有工作流，一次开始提交多个独立 Job。提交不等待前一个 Job 执行完成；不是硬件同时触发或进程同一时刻开始的承诺。 |
| 无新增持久声明 | 运行目标是当前打开工程的临时选择。保存的并发数沿用 `runtime.maxConcurrentJobs`；不新增工位管理文件。 |
| 并发设置 | 默认 2，正整数限量，显式 `null` 关闭 Job 数量限制。0/-1 仍非法。并发不保证无限算力/显存、设备独占或硬实时节拍。 |
| 长循环 | 现有 While V2 显式 `unlimited`，仍按布尔条件判断，响应取消/超时。不把 maxIterations=0 暗改成无限，不在每帧创建新 Job。 |
| 两拍逻辑 | 仍由现有全局变量及 Switch 构建；自增输出为本帧 n，第二拍先复位变量，不改变已经返回的 n=2。调度器不保存隐藏拍次。 |
| 运行观察 | 每个 Job 独立状态、节点结果、图像检查上下文；可切换查看、停止所选、停止全部、单独重启。首次批量开始前同步一次工程，其他 Job 在运行时禁止重载。 |
| 页面展示 | 使用已有 resultScopes 的根入口/调用路径派生当前 Job 的页面；不再配置一张工位页面归属表。循环体结果逐帧发布，不等待长期 While 根结束。 |
| 资源与清理 | 扩展图像导出槽，不再固定只能给两个 Job 导图。事件队列/诊断状态有界，数据库事件保留对普通 While 同样生效；关闭清理全部自有 Job。其他图像、资产、元数据预算仍保留。 |
| 错误处理 | 部分启动/停止失败不重启健康流程补偿；启动结果不确定查询同一请求，不盲重发。业务 NG 暂缓不代表忽略技术错误。 |

### 本轮测试发现并修复的具体问题

1. Designer WorkspaceChrome 会重建工具栏，移除早期添加的选择控件。运行目标、Job 下拉和停止全部已放到右侧固定运行摘要，并检查 1060/1280 像素原生窗口。
2. Chrome 原先用单 Job 的 `isJobRunning` 禁用开始，导致停止一个流程后无法在另一个仍运行时重启。现在使用通用 manager 的目标级可启动/可停止状态。
3. 多 Job 高频持久事件写入时，全局变量写入曾出现 `database is locked`。仅对 `BEGIN IMMEDIATE` 获取写事务做有期限随机短等待；事务内读改写和 commit 不重放。旧 counter 仍返回 `E_COUNTER_BUSY`。
4. 工程切换释放旧工作流的图像检查上下文；复用的检查器重新绑定当前工作流通知，避免串到已关闭工程。
5. 生产窗口从单流程增加到多流程、再增加第三流程时补建标签，保留已运行 Job 和既有多流程页面对象。
6. 长期事件订阅期间，以真实 `job.started` 事件更新 RUNNING，避免界面一直停在 ACCEPTED。
7. 已采集的全局变量/计数值能在页面渲染；读取结果快照，不在显示端读取可能已归零的实时变量。
8. Designer 图像检查原有“两会话”上限也会阻止第三个 Job。Runtime 现在按工程工作流数量/并发设置给检查会话配置准入额度，显式不限量时不设会话数量门槛；单会话保留最近两次执行和原有全局字节/读取预算不变。已用 Designer 4 个 Job、不限量模式 3 个 Job 验证。
9. 普通新 Start 达到展示额度时，仅可回收已终止且确实完成 worker、读者和导图退役的旧展示；不停止正在运行的 Job，也不把“状态终态”当作已释放资源。验证了上限 2 下停止 A、保留 B、启动另一个入口 C。
10. 共用运行目标表单放在 `emo_master.ui`，操作端不依赖 Designer 应用模块。停止全部遇到单个请求异常仍尝试其余流程；在订阅/停止工作线程实际退出前仍禁止编辑和重载。

## 3. 用户查看方式

1. 重启源码版 Designer；当前已运行的旧进程或旧 exe 不会自动更新。
2. 打开工程，进入 **运行 → 运行目标与并发…**，或右侧运行摘要的 **运行目标…**。
3. 勾选要独立运行的入口工作流，例如 `station1-run`、`station2-run`。不要同时启动它们的循环体和内部子流程。
4. 点击一次 **运行流程**。右侧下拉切换查看哪个 Job；工具栏 **停止运行** 只停止所选，右侧/运行菜单 **停止全部** 停止全部。
5. 若要增加并发额度，在没有 Job 运行时修改上限，按既有工程保存机制保存。上限支持撤销/重做；运行目标勾选不写入另一份声明。
6. 操作端通过 **运行目标… → 开始** 使用同样的已有入口；项目自启动兼容行为仍只使用默认入口，不暗中启动所有子流程。

相机、PLC、TCP 参数仍在各自节点中。硬件正常链示例的模型和现场参数尚未齐全，只供查看结构和替换边界测试，不能当作已完成现场工程启动。
