## 局部实现与可验证收益

旧路径对每张 BGR 图先做 NumPy 通道反转并复制到 RGB，再复制到拥有独立内存的
QImage。Qt >= 5.14 已支持 BGR888；本项目 PySide2 >= 5.15 可以直接使用。
连续 BGR 数组现在只需要最终 QImage.copy；非连续数组仍最多一份有界连续 scratch。
输出仍独立拥有像素，Runtime 的只读数组可直接输入。灰度和 BGRA 路径不变。

独立 offscreen ABBA 微测量，每组 32 次相同 1080p 图像：旧转换均值 6.61/6.49ms，
直接 BGR 均值 0.93/0.94ms；缩放绘制均值约 0.33–0.36ms。转换到 ARGB32 的完整
像素一致。这个结果仅证明转换步骤减少工作，不证明端到端吞吐或历史丢图已修复。

PNG 参数对比也原样保留；几个候选均未比原默认编码更快，因此没有改 PNG 编码。
