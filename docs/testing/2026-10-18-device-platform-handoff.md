## 软件人工验收

| 步骤 | 操作 | 应观察到的结果 |
|---|---|---|
| 1 | 正常 Designer 拖入设备算子，选已有设备、新建设备及取消 | 设备来源明确；取消无半成品；无自动连接/采集 |
| 2 | 两节点共享设备，分别继承/覆写；修改默认后撤销 | 覆写即使等于默认也保留；来源互斥；一次撤销完整恢复 |
| 3 | 旧工程迁移预览，检查 keep、变量、无限等待和资源/现场目标 | 不猜硬件；逐项确认；保存前不改原文件；旧值不伪装成继承 |
| 4 | 导入含 Dispatch/Join、设备及变量的工作流包，核对复用/新建设备 | 引用映射正确，新建设备默认禁用，取消不留内容 |
| 5 | 模拟采集分给两个消费者，持续运行并停止 | 同帧同周期、独立调用；持久消费者；满队列明确报错；停止后资源退休 |
| 6 | 本地修改并保存，比较后只选一项写入 | 保存不改在线；未选无效草稿不夹带；依赖需明确确认 |
| 7 | 持续生产时改普通参数；再对相关设备连接选择停止/排空 | 参数按新周期生效；旧消费者保留旧版；无关任务继续；连接结果独立显示 |
| 8 | 查看在线/历史只读图并选择旧 Job | 使用对应快照；旧结果不套新参数；无法编辑在线图 |
| 9 | 导入 page_image/icon，设置静态图片/导航图标，明确上传并发布 | 上传不是提交；纯外观不停止 Job；静态页不额外取图；动态来源不能并存 |
| 10 | 删除 Designer 测试源资源后重启测试 Runtime | 已上传提交的资源仍可用；未上传本地资源不能被假装恢复 |

| 12 | 断开 Designer，随后重连读取 | 生产生命周期由 Runtime 持有；读到最后提交版本而非本地新保存文件 |

## 实机验收准入

1. 备份工程、Runtime SQLite、现场 IP/网卡、PLC 点位和相机触发配置，记录 SDK/固件版本。
2. 使用隔离设备和明确授权的测试点位，不以开发测试指令操作生产 PLC。
3. IMV 网络功能目前仅接受已核对 ABI 的 2.4.2 系列。其他版本需先核对头文件/结构体并补测试。
4. 物理改址前停止相关使用者、明确断开并暂停设备，核对 MAC、cameraKey、原/目标 IPv4。
5. ForceIP 不承诺断电持久化；修改后核对读回并人工决定工程连接更新及重连。
6. UNKNOWN 必须查原请求回执并检查实物状态，不自动重复写 PLC、触发或改 IP。

## 必须另行执行的实机项目

- 两 Job/诊断共享同相机或 PLC 的 FIFO，以及独立设备不互相阻塞。
- 真实 SDK 取消无限硬触发、原生卡死/Host 退出、迟到帧、重连帧号和自由运行曝光同步。
- PLC 断链恢复、已写但回执丢失、停止/排空/重连的现场效果，确认没有自动重写。
- Runtime 网卡发现、MAC 匹配、改址冲突与实物回读，确认 ForceIP 的设备实际持久性。
- 真实模型/资源、旧现场工程迁移、完整冻结 GUI 和干净 Windows 安装环境。
