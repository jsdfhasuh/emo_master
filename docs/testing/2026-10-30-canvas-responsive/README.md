### 修复前失败与后续结果

2. 九文件网格／属性组合首次 32 failed、46 passed；32 项均为 Grid 专用页面／容器夹具仍使用新默认响应式类型。明确页面 Grid 后，三文件第二轮仍 8 failed、25 passed，原因是后加嵌套容器尚未明确 Grid。修正这些夹具后 33 passed；其余六文件保留第一轮有效的 45 项通过。未弱化几何与手柄断言。完整记录：[首次失败](evidence/grid-first-failures.xml)、[嵌套失败](evidence/grid-nested-failures.xml)、[最终网格通过](evidence/grid-final.xml)。
3. 合法待提交长标题／32px 字号后开始 resize，曾出现 number 预览 `632×159`、提交 `632×285`，image 预览 `632×213`、提交 `632×344`，并伴随已删除 QWidget／QLabel 的包装对象事件异常。现已先接受属性并保留原生拖动手柄，再由同一布局测量生成预览；数值／图片／表格 × 根／嵌套 6 例的预览与提交误差不超过 2px。
4. 菜单编组／取消编组／对齐曾各 reload 两次；现真实 QAction 各只 reload 一次。缩放 0.5／1.5 时拖影与热点曾保持原尺寸；现影像和屏幕热点随缩放，MIME 仍使用布局坐标。不同尺寸多选从 B 拖动曾拿 A 大小计算吸附；现使用真正按住的 B。上述均在最终 29 例中有回归。
