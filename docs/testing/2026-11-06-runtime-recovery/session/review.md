# Web 会话恢复补丁独立复核

复核者：ChatGPT Web 根代理。基线 `cdf1250ccc41b78f79b25b87e6db197809875384`；复核工作树的最终 Web diff、实际前后端测试源码及保存的红绿日志。没有重复运行完整 Web 套件，也没有把组件测试计作人工浏览器验收。

## 结论

未发现阻断集成问题。

后端仍先验证实际会话和权限，再验证 Origin，最后比较 CSRF。只有最后一步真正不匹配时返回 `403 + CSRF_MISMATCH`；普通权限和 Origin 拒绝不进入恢复通道。原 HTTP 状态和 detail 保留，不自动创建或撤销会话。

前端只对专用错误码或原有 401 触发会话恢复，保留请求代次检查；重新进入后的旧请求晚到拒绝不能再次清掉新会话。入口请求及显式忽略恢复的查询也有排除，避免入口递归。请求抛出 ApiError 后结束，不自动重发保存、发布或运行命令。

App 复用已有 endSession：清理当前运行视图，展示服务端身份对应的重新进入入口。Editor 源码没有变化，现有草稿备份与模块内存存储跨卸载/重挂保留未保存内容。实际 App/Editor/API 用例覆盖 sessionStorage 正常及不可用、保存及发布两个触发动作；实际账号、目标、工程切换使用服务端身份隔离恢复内容。

真实后端测试首先合法保存起始草稿，再更新共享 cookie，以旧 CSRF 提交并验证草稿、revision、cookie 均未变化。随后明确重新进入复用有效会话，再次显式保存成功。该夹具修正避免把空编辑器每次新建页面 ID 的差异误判成未授权写入，没有放宽正确性断言。
