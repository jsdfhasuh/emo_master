## 新缺陷的根因

`JobSupervisor._retireDispatch()` 写入 `dispatch.source.ended` 和 `dispatch.group.retired` 时未传 `projectId`、`workflowId`，`EventStore.append()` 使用空字符串默认值并持久化。

原始数据库中，6个Dispatch根Job各有这两条事件，共12条。jobId正确，工程和工作流字段均为空；全库非空jobId而空projectId的记录恰好就是它们。

生产Web客户端 `GrpcRuntimeClient.job_events()` 将事件身份与所选RunState比较，正确拒绝空工程身份。异常为 `RuntimeRejected(IDENTITY_MISMATCH)`，它继承ValueError，由正式HTTP处理器映射422。整页失败后游标不推进，后续轮询重复遇到同一批坏事件。
