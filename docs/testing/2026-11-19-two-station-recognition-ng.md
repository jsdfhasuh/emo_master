# 双工位工程识别 NG 与下一组触发

本次修改本机双工位工程 `two_station_screw_vision.emoproj`。两工位各自使用原有拍次变量。用户指定任一拍识别 NG 即结束本组，下一次外部触发从首拍开始。成功首拍后若次拍 NG，已经完成的首拍补偿保留，次拍跳过机器人报文。工程没有新增设备握手。

## 工程行为

| 触发条件 | 工程判定 |
| --- | --- |
| 任一 YOLO 路线没有选定的检测框可供裁剪 | 使用既有 `onMissingCrop=skip`，本路缺少测点计数按零处理 |
| 首拍 A 或 B 测量得到零个或多个最终点 | 两路各需恰好一个测点；任一路不满足，本拍 NG |
| 次拍孔心测量得到零个或多个最终点 | 本拍 NG |
| 二工位 0.75 匹首拍传统 B 路没有可选轮廓 | 现有轮廓选择算子返回空集合，判为 NG |

判定使用既有数值、比较、条件分支和条件选值算子。首拍 NG 将本工位拍次复位，次拍沿用原有复位。每次 NG 都保留当前图像，监看页与本拍详情显示“识别 NG”，本拍不提供可用于补偿或发送的点或回执。正常路径继续执行原单点校验、参考点、标定和输出流程。

YOLO 沿用工程的目标序号（当前为置信度排序第一个）。原设计会合并的轮廓、传统 B 路按周长选首项的规则均保留。单一测点落在错误孔位、单点偏差超差、产品装配质量均超出本次判据。
