# 连线可读性验收工程

本目录只使用数值常量和数值比较，不含相机、PLC、网络发送、模型、文件写入或私有工程数据。`project.emoproj` 可直接从 Designer 打开；不需要设备配置，不必启动检测来验收显示。

| 工作流 | 用途 | 正常执行结果 |
| --- | --- | --- |
| fanout | seed 同一输出分到 4 个比较节点；另一个参考信号、重名节点、长中文标题及汇合 | result0-result3 均 false（7 >= 8） |
| sparse | 稀疏连接、普通选中与端口悬停 | result0=false |
| dense | 5 个数值源、20 个比较节点、60 条真实边 | 按 source=7+(i%5)、reference=7+((i+1)%5) 比较 |
| crossing | 调换两个节点的垂直位置，检查不同信号/多端口与选边 | 与 fanout 相同 |
| blocked | 故意让源节点和比较节点重叠，只查看受阻提示 | 数据图合法；重叠不代表执行错误，不在此测试中运行 |

布线是启发式避障，不承诺每次都产生相同数量的公共段；同源信号只有路径重合的部分才会共用干线。需要时在测试副本中移动节点以构造更多分支，不能把“没有可合并段”当作画布丢失边。

生成器为 `generate.py`，从仓库现有算子 manifest 读取端口和默认参数，运行后确定性生成工程。密集压力图（100 节点/300 边）的固定几何由 `scripts/validate_flow_edge_readability.py` 的 `populate(stress=True)` 生成，仅为显示层自动化夹具，不冒充可执行业务流程。

dot 的步骤、证据格式与停止条件见 [桌面验收清单](../../docs/testing/2026-10-12-dot-flow-edge-readability.md)。共享干线点击后选择具体支路；菜单 hover 只预览，只有点击才改变选择。删除、撤销和保存重开必须在独立副本中进行。

从空白工程搭建的参考目标为：两个数值节点（7、8）、四个数值比较节点、每个比较的 left 接 7、right 接 8，共 8 个输入连接；再配置四个工作流 boolean 输出并连接 result，共 12 条连接。加上输入/输出边界共 8 个节点。先真实操作工具箱和接口编辑器，不通过工程 JSON 绕过入口。
