# 相机、PLC 与全局计数器现场联调说明

## 1. 测试目标

这份项目用于现场连接真实华睿 IMV 相机和三菱 SLMP/MC 3E PLC 后，分阶段验证：

1. 相机自由运行采图。
2. PLC M 位与 D 寄存器只读通信。
3. PLC 备用 D 寄存器写入。
4. PLC 布尔信号驱动持久计数器。
5. 相机采图成功信号驱动同一个持久计数器。
6. PLC 硬件脉冲触发相机，采图成功后计数并写回 PLC。
7. 跨工作流、跨 Job 和 Runtime 重启保持计数值。

项目文件：`project.json`

项目入口默认是 `01 相机自由运行采图（只读）`。误点“开始运行”不会写 PLC。

`uint32` 占两个连续 D 寄存器。因此模板会同时使用 `D798` 和 `D799`。电气或 PLC 工程师必须确认这两个寄存器都为空闲测试区，而不是只确认 D798。

如果现场地址不同，需要修改项目中所有同类节点，不能只改一个工作流：

- 相机节点：工作流 01、05、06。
- PLC 读取节点：工作流 02、04、05、06。
- PLC 写入节点：工作流 03、04、05、06。

建议修改完成后保存项目，再用文本搜索确认旧 IP `192.168.1.10`、`192.168.1.20` 和旧地址没有遗漏。

## 3. 上电与写入安全条件

在运行工作流 03、04、05、06 前，必须满足：

- 设备处于手动、调试或安全停机状态。
- PLC 工程师已确认测试用 M/D 地址及两个连续 D 寄存器不会驱动执行机构。
- 已明确 PLC 的字节序和双字组合方式；本项目按 SLMP 低字在前写 `uint32`。
- 相机硬触发线电平、电气隔离和公共地符合相机与 PLC 输出规格。
- Runtime 的 `maxConcurrentJobs` 已设为 1，现场不要并行启动多个硬件 Job。

不要在未确认地址时运行“PLC 写入”类工作流。

## 4. 现场软件与网络准备

1. 安装华睿 MV Viewer/IMV Runtime，并确保程序能找到 SDK DLL。必要时设置 `HUARAY_MV_VIEWER_ROOT`。
2. 用厂商工具确认相机能枚举、能采图，并记录实际 IP、曝光、Gain、像素格式和触发线设置。
3. 给计算机相机网卡设置同网段静态 IP；检查防火墙、巨帧和网卡节能设置。
4. PLC 侧启用 SLMP/MC 3E 二进制 TCP 服务，确认端口和访问范围。
5. 从现场计算机测试相机与 PLC IP 连通性，并确认 SLMP TCP 端口可连接。
6. 加载 `project.json`，点击“校验项目”。
7. 运行某个流程前，右键对应工作流标签，选择“设为入口工作流”，保存，再点击“开始运行”。

## 5. 工作流说明

| 编号 | 工作流 | 是否写 PLC | 用途 |
| --- | --- | --- | --- |
| 01 | 相机自由运行采图（只读） | 否 | 独立确认相机、SDK、网络和图像 |
| 02 | PLC 信号与计数寄存器读取（只读） | 否 | 读取递增位、复位位、PLC 计数字 |
| 03 | PLC 备用寄存器写入 123 | 是 | 在已确认的备用 D 双字区验证写入 |
| 04 | PLC M 信号驱动计数并写回 D | 是 | 验证 PLC 是独立布尔信号来源 |
| 05 | 自由运行采图成功计数并写 PLC | 是 | 验证相机成功信号是独立来源 |
| 06 | PLC 硬触发采图计数并写回 PLC | 是 | 验证完整生产式硬触发链路 |
| 07 | 全局计数只读（无需硬件） | 否 | 查看持久值和重启后保留情况 |

工作流 04、05、06、07 使用同一个计数器名称 `现场联调计数`。这用于证明计数器并不属于某个相机节点或 PLC 节点，而是由不同工作流和不同信号来源共享。

4. 在流程 03、04、05、06 中核对 PLC 写地址。

预期：项目校验通过；入口流程不包含 PLC 写节点；所有写节点指向同一个已批准的备用 D 双字区。

### T-03 PLC 只读通信

操作：

1. 将工作流 02 设为入口。
2. PLC 侧依次设置以下状态，每次运行一次 Job：

   - M500=1，M501=0；

4. 对照工作流输出的 `incrementSignal`、`resetSignal` 和 `plcCount`。

预期：三个值与 PLC 监视器完全一致；此流程不修改 PLC。

### T-04 PLC 备用寄存器写入

前提：PLC 工程师已书面或现场确认目标 D 双字区允许覆盖。

操作：

1. 将工作流 03 设为入口。
2. 再次核对写入首地址和 `uint32` 类型。
3. 运行一次。
4. 在 PLC 监视器查看目标两个 D 寄存器。

预期：Job 为 `COMPLETED`；写回值为 123；以模板地址为例，D798 低字为 123、D799 高字为 0；receipt 中地址、类型、字数正确。

### T-05 PLC 信号驱动全局计数

操作：

1. 打开“运行 → 全局计数器…”，将 `现场联调计数` 清零；若不存在则新建。
2. 将工作流 04 设为入口。
3. M500=0、M501=0，运行一次。
4. M500=1、M501=0，运行一次；保持 M500=1，再运行一次。
5. M500=0、M501=1，运行一次。
6. M500=1、M501=1，运行一次。

预期：

- 两个信号均为 0 时只读，计数保持 0。
- M500 保持为 1 时，每运行一个 Job 都递增一次，依次得到 1、2。
- M501=1 时复位为 0。
- M500 和 M501 同时为 1 时，reset 优先，结果仍为 0。
- 每次 Job 完成后，PLC D 双字值与全局计数器窗口一致。

重要：M500 是电平输入，不是内置上升沿检测。PLC 若一直保持 M500=1，多次启动 Job 就会多次计数。现场程序应使用脉冲/握手，或确保一个事件只对应一个 Job。

记录：实际序列 ______ → ______ → ______ → ______ → ______；结果 `[  ] 通过  [  ] 失败`

### T-06 自由运行采图成功后计数

操作：

1. M501=0；通过管理窗口把 `现场联调计数` 清零。
2. 将工作流 05 设为入口。
3. 连续运行三次。
4. 断开相机网络或使用错误相机 IP，运行一次超时测试，然后恢复配置。

预期：

- 每次成功采图后计数依次为 1、2、3，PLC D 双字同步为相同值。
- 相机无法采图时 Job 失败，计数仍为 3，PLC 保持最后一次成功写入值。
- 这条流程证明相机只是布尔信号来源之一；计数器本身不依赖图片内容。

记录：成功序列 ______ / ______ / ______；失败后值 ______；结果 `[  ] 通过  [  ] 失败`

### T-07 PLC 硬触发相机完整链路

前提：PLC 数字输出已正确接到相机触发输入，触发电平、Line 号和边沿均已由电气确认。

操作：

1. 将工作流 06 设为入口。
2. 确认相机节点为 `hardware`、现场 Line 和边沿设置正确。
3. M501=0；记录当前计数。
4. 先启动 Job，使相机进入等待触发状态。
5. 在 10 秒超时内由 PLC 输出一次有效触发脉冲。
6. 再启动一次 Job但不发脉冲，验证超时行为。

预期：

- 有脉冲时取得一帧，计数加 1，并把新值写回 PLC。
- 无脉冲时出现 `E_CAMERA_TIMEOUT` 或等价超时错误；计数和 PLC 值不变。
- 每个脉冲只对应一次有效 Job 和一次计数。

记录：触发线 ______；边沿 ______；成功后计数 ______；无脉冲错误 __________________；结果 `[  ] 通过  [  ] 失败`

### T-08 跨来源共享与 Runtime 重启

操作：

1. 先用流程 04 让 PLC 信号递增一次。
2. 再用流程 05 或 06 让相机成功信号递增一次。
3. 用流程 07 读取当前值。
4. 完全关闭 Runtime；如果 Runtime 由 Designer 托管，则退出 Designer。
5. 重新启动并加载项目，运行流程 07。

预期：两个不同来源累计到同一个 `现场联调计数`；Runtime 重启前后数值一致；管理窗口显示同一个名称和更新时间。

记录：PLC 后 ______；相机后 ______；重启前 ______；重启后 ______；结果 `[  ] 通过  [  ] 失败`

### T-09 管理窗口在线操作

操作：

1. Job 空闲和 Job 运行期间分别打开非模态“全局计数器”窗口。
2. 验证自动刷新、手动刷新、设值和清零。
3. 保持窗口打开运行一次流程 04/05/06。

## 7. 重要行为边界

- 全局计数器范围是 `0..9223372036854775807`，但当前 PLC 模板使用 `uint32`，只能写 `0..4294967295`。
- 如果计数值超过 PLC `uint32` 范围，计数事务可能已经成功，而后续 PLC 写入失败；计数不会因下游失败自动回滚。
- 计数器按 `(projectId, name)` 持久化，不保存在 `project.json` 中。
- 同一个计数器可以由相机成功、PLC 位、视觉比较或其他布尔节点驱动；项目中的多个来源只是联调示例。
- 硬触发模式下应先启动 Job 再发脉冲，否则相机尚未进入等待状态时的脉冲可能丢失。
- PLC 写算子按字设备写入，不支持直接写 bit；M500/M501 的置位与复位由 PLC 程序或工程工具完成。
