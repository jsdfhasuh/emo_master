# 通用页面控件高级外观

## Why

现有页面设计已具备基础外观、状态映射和页头宿主按钮配置，但工程师仍无法通过统一入口进一步定制多数页面控件。需要在现有 Designer 和 Web 编辑流程中增加常用高级选项，以及分别适用于 Qt 和浏览器的 QSS／CSS 编辑能力，并让配置在保存、数据刷新和运行显示中持续生效。

用户已明确：支持范围是 **13 种可见组件＋页头开始／停止按钮**。旧图稿 v0.5 中“先覆盖按钮、状态行、数值卡”的描述只能作为实施顺序，不能作为最终交付范围。本 change 的 v0.7 审查版延续 v0.6 已确定的完整范围，并明确新增能力的目标效果与最小验收方式。

## What Changes

- 为 13 种可见组件和 2 个页头宿主按钮开放适用的高级外观；`spacer` 继续只处理布局。
- 扩展常用颜色、边框、图标排列及适用的按钮状态外观；复用现有文字、字号、圆角、内距、图标显隐与绑定。
- Designer 在原外观弹窗增加自定义 QSS、部位选择器提示及真实 Qt 局部预览；Web 在原属性区提供对应 CSS 编辑与浏览器预览。
- 保存 `customStyle.qtQss` 与 `customStyle.webCss`，各自包含 `enabled` 和 `code`；修改一端保留另一端，停用保留代码。
- 将代码限定到当前组件自身部位或选定宿主按钮，处理 Qt 子控件样式／自绘更新和 Web 行内样式覆盖。
- 沿用工程保存、Web 独立草稿和发布转换；样式进入对应运行端，预览不执行实际业务动作。
- 交付同一示例工程、Web 页面包、逐类型覆盖记录和真实截图。三个示例控件完成不等于本 change 完成。
- 全类型做基本效果覆盖；共享流程用代表对象验证并复用证据。按目标配置实际回放图标排列、状态、边框和文字等能力，不新增通用样式编译器、全属性沙箱或全组合测试。

## Capabilities

### New Capabilities

- `page-advanced-appearance`：可见页面组件的高级表单配置、原生 CSS／QSS 编辑、对象作用域、预览、保存发布及运行显示。

### Modified Capabilities

无。本 change 沿用 V1.3／V1.4 已有的组件、绑定、页面动作、页头宿主行为和保存发布语义，仅增加高级外观能力。核查基线的 `openspec/specs/` 尚无正式能力文件；相关历史规格仍位于先前 change，不能对不存在的主规格编写 `MODIFIED`，也不复制其既有要求重新声明为新增。

## Impact

- 基线：`jsdfhasuh/emo_master` 的 `main` 在 2026-11-20 核实为 `6cbff0dcbea671663cf9ab773c6ce5c81690da35`。实施前核对本地实际 HEAD 与后续差异。
- 共享模型／契约：`emo_panel_protocol` 模型、发布模型、生成 Schema／TypeScript／SDK，以及工程发布转换。
- 作者端：Designer 原属性面板／外观弹窗；Web 原属性区及编辑画布。
- 渲染：Qt 公共页面渲染、页头按钮、图像自绘、集合表格、SQLite 表格／列表及页面导航；Web 对应组件和宿主按钮。
- 数据与持久化：现有工程、Web 草稿和发布包保留两端样式；不建立自动回写 `.emoproj` 的流程。
- 范围外：全站主题服务、页面级原生样式全局级联、CSS→QSS 自动转换、新业务动作、工作流／设备改造、Qt6／QML 迁移。
