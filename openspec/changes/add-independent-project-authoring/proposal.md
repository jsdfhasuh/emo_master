# 独立工程草稿与 MCP 编排服务

**交付版本：v7 · 协议字段与测试基线对齐版；日期：2026-11-13；状态：四个协议字段及 ROI 测试修复已存在，目录接入与本变更新接口仍待完成。**

**计划参考基线：`b61a96f6d8135497531eabf18245118de253ee03`（上轮已核对的 main / PR #13 合并提交）。** 本版依据已核对的 `4a602120`、`f663c007` 和 Runtime 返回装配更新文档；不要求执行时回退，也不宣称本轮重新获取了远端最新 HEAD。

## Why

AI 需要在不打开或控制 Windows Designer 的情况下，了解目标环境真实支持的算子，独立生成可继续在 Designer 中编辑的正式工程。现有 Designer 工程能力应优先复用，避免 Web 再维护一套编辑规则；同时不把桌面整体重构、旧 Web 迁移或复杂防御体系作为新服务的前置条件。

## What Changes

- 新建独立 Web 后端：完整工程草稿、语义编辑、撤销重做、保存和恢复；HTTP 与可选 MCP 使用同一业务服务。
- 将算子能力发现列为首期能力：摘要检索、完整详情、设备类型声明和实际已实现的编辑操作，区分算子功能、编辑支持和工程预检结果。对新 ROI 组合区域等嵌套参数递归保真，不因其提供桌面专用编辑器而要求移植界面。
- 复用已声明并生成的四个协议字段，接通真实 Runtime 填值、实际客户端解析和 HTTP/MCP 输出；区分未提供元数据与明确空列表，不重复新增字段或改号。
- 沿用正式工程模型、格式与读写。直接复用已有无界面代码；只有 Web 实际需要而仍耦合界面的规则才局部提取，同时适配对应 Designer 调用。
- 提供资源上传/替换、正式工程导入、单文件和带资源 ZIP 导出。
- 增加独立候选工程预检，复用目标 Runtime 真实声明及编译器；不替换在线工程、不启动候选任务、不自动连接现场设备。
- 补明确协议版本与请求取消、客户端文件往返、可定位诊断及本地校验/目标预检分工；让“检查 → 修复 → 再检查 → 下载”可实施。
- 按 A–D 四阶段交付，七组业务验收复用同一图像示例；必要桌面适配随提取同步完成，阶段 D 通过公开命令验证代表能力，不新增专项测试或 CI。

本包替代旧 v2–v6 的实施约束；保留 F1–F6、v6 的嵌套算子和页面快照要求。本次只扣除已存在的协议声明/生成工作，并明确剩余目录映射和版本测试依据。四个协议字段存在不代表 Runtime 已填值或 MCP 已接通；25 项接口实施与验收任务仍未勾选，任务 1.1 不整体标为完成。本包不授权推送、合并或发布，不恢复旧版已取消范围。

## Capabilities

### New Capabilities

- `project-draft-authoring`：独立完整工程草稿、语义编辑、事务、保存与修订。
- `operator-capability-discovery`：目标算子与设备声明、编辑能力和支持边界的可查询信息。
- `project-resource-delivery`：资源登记、替换、正式工程导入及可继续编辑的交付。
- `candidate-project-precheck`：指定草稿快照在目标 Runtime 上的无执行预检。
- `mcp-authoring-access`：HTTP/MCP 统一入口、工具契约、工作区凭据与文件往返。

### Modified Capabilities

无。本包继续以五项新增对外能力组织 delta；协议字段声明先行落地不等于这些能力已经验收。上轮已确认 v6 原始材料归档在 `docs/plans/2026-11-13-independent-project-authoring-v6/`，它不是本次活动变更目录，不覆盖其原始文件或摘要。实施前检查仓库实际 `openspec/specs/` 与 `openspec/changes/`：若已有同义规范或任务进度，比较合并，不重复创建，也不抹去已完成记录。

## Impact

| 范围 | 预期影响 |
| --- | --- |
| 新 Web 服务 | 草稿、目录、资源、导出、预检入口；不要求新建完整浏览器流程画布 |
| Designer 底层 | 必要的纯逻辑复用/提取及直接受影响调用；现有界面行为保持 |
| Runtime / SDK / proto | 四个已声明字段不重建；完成真实填值与目录解析，确认实际加载的协议代码具备字段；候选 ZIP 流预检仍需新增。proto 后续若变化，沿用既有生成检查 |
| 测试 | 复用被修改代码已有测试，补正常路径及直接反例，完成一次实际客户端交付 |
| 部署 | 保留目标 Python 3.10；单工作区、单服务进程及本地持久化；MCP 可关闭 |

不纳入：旧 Web/API/数据迁移，多租户/OAuth 适配矩阵，全桌面重构，独立包发行前置要求，任意插件沙箱，分布式锁，完整审计/幂等账本，自动发布或运行工具，以及与本轮无关的相机/PLC 硬件验收。
