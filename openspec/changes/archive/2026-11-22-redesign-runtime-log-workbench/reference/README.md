# 日志工作台完整方案：交互与视觉参考

本目录是 `redesign-runtime-log-workbench` 完整整合方案的唯一交互参考入口。双击 [index.html](index.html) 查看导航，或直接打开 [prototype.html](prototype.html)。不需要另一个原型或旧方案压缩包。

全部交互样例使用模拟数据、模拟时间和模拟连接，没有真实 Runtime、相机、PLC 或数据库操作。正式产品继续使用既有 PySide2 / Qt Widgets；HTML 只用于说明交互。

## 当前规则与使用顺序

1. 数据范围、身份、状态、时间边界和验收要求以完整的 [设计](../design.md)、[规格](../specs/runtime-log-workbench/spec.md) 与 [验收清单](../acceptance.md) 为准。
2. 最新 `prototype.html` 与两张 `target-…` 目标图表达当前首页、日期筛选、技术条件、执行阅读和详情关系。
3. 其余五组静态图仅保留仍适用的执行结构、设备和来源关系；它们不覆盖最新原型的默认布局或完整规格。
4. 两张 `q1-…` 图是 `fa4b72d751189c2689882a0a0d127fd280a35fde` 的 Qt 基线存档，不是整合方案的新实现验收。

实施时先核对当前代码，保留已符合完整合同的能力，完成尚有差异的部分。完整文档不意味着重写已经实现的 Runtime、查询、日志存储、设备诊断或调试窗口。

## 完整交互范围

- Runtime 的运行任务、未关联任务的系统事件，以及独立的 Designer 本机日志来源。
- 首页“运行中 + 最近已结束”，实际任务状态、开始/结束/运行耗时、来源明确的关联任务。
- 单 Job 内真实工作流调用、普通子调用、While / ForEach / Repeat 轮次和连续运行的多次根调用。
- 高级条件、常用/技术条件分层、精确 ID 与原始轮次路径、已加载范围提示及上下文往返。
- 右侧易读详情、原始 JSON、复制、框架输入输出摘要、指标与诊断、主动算子日志；现有独立调试入口复用呈现。
- 近期设备诊断下钻及返回、Designer 当前会话与本机文件。
- 原型未完整模拟的服务端历史查询、更早任务目录、固定上界完整导出、能力协商及有界窗口，仍按完整规格和验收清单实现，不因图中没有按钮或全量数据而删除。

## 子工作流与关联任务是不同关系

**普通子工作流调用**仍属于同一个 Job。在任务内部按真实调用 ID、父调用 ID、节点执行与轮次路径组织；它不自动成为首页另一条运行任务。

**关联任务**指已经取得明确来源/运行组关系的独立 Job。它有自己的 Job ID、状态和日志。原型的“本批采集”已经完成，而检测任务与保存结果任务仍运行，展示的是这类独立 Job，不是把 While 轮次或普通子调用算成两个新任务。

只有真实关联记录才能支持“还有 N 个关联任务未结束”。`active` 或 `owns_resources` 本身不能说明正在运行的是哪个子流程，也不能证明正在关闭相机、写入数据或释放设备。其他状态说明按完整设计中的实际证据显示。

## 日期、筛选与往返合同

- 日期输入允许毫秒，开始包含、结束不包含；清空表示不限，两端相等是合法空区间。
- 开始晚于结束时保留编辑值与之前有效结果，行内提示“仍显示此前有效条件的结果”；纠正为有效范围后再应用。来源日志与任务日志一致。
- 样例使用浏览器 `datetime-local`，并明确“本机时区示例：UTC+08:00”。为保证不同电脑打开同一组离线数据时一致，样例按这个偏移解释输入；正式 Qt 必须使用真实本机时区，不能硬编码八小时。
- 工作流、节点和调用 ID 精确匹配；原始路径按真实数组逐段匹配。例如 `1/0` 与 `1/1` 属于不同嵌套轮次。条件联合生效，WARN 条件可能使某条路径没有命中。
- 收起高级/技术条件不清空值，技术输入和普通名称选择使用相同真实 ID；已修正同绑定控件的输入焦点恢复。
- 从来源任务查看关联 Job 后返回，使用轻量 UI 书签恢复视图、筛选、选择及展开状态，不复制事件记录或新建账本。

## 文件与验证性质

详见 [visual-guide.md](visual-guide.md) 的图像清单及 [visual-manifest.json](visual-manifest.json) 的来源、大小和摘要。

- `prototype.html` 是离线自包含交互样例，无外网 CDN、宿主 API 或真实后端请求。
- `target-…` 图片是静态目标结构示意，不是 Qt 截图，也不规定像素级还原。
- 五组旧结构图保留的是当前仍适用的关系，不是独立的新界面要求。
- `q1-…` 是旧实现实际 Qt 存档，只说明基线能力。
- `operator-coverage.json` 保留原基线 82 个算子的静态清单；算子记录和计数未更改，仅澄清元数据说明。主动日志调用数不等于完整日志功能覆盖率，也不是 82 算子运行验收。
- `verification.json` 继承最新原型的 Node VM + 最小 DOM 替身检查，记录本次复制与链接核对。没有把交互脚本检查或静态图片当成浏览器、Qt、真实 Runtime / 硬件验收。
