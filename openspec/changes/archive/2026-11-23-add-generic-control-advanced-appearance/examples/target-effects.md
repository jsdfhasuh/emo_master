# 目标效果与最小回放配置

审查版：0.7。本文固定验收使用的参数。可编辑配置和正式 Web 包随示例一起交付。[示例工程](../../../../../examples/advanced_appearance/README.md)

## 1. 如何使用

复用全类型示例工程中的启停按钮、方向判定、两条复核结果行和角度数值，从现有作者端入口配置。下面为人可读参数，不假装是能通过当前旧模型校验的 JSON。

第 05／06／12 页表达整体颜色、边框与图标效果，第 08／13 页表达弹窗到画布交互。参考图有放大、缩小与不同历史页面底图，不能从图稿像素反推工程的字号和几何参数；实际回放以本文为准，同一次验收各视图采用同一工程配置，不用未记录的手工调整补效果。

页面布局、图片、数据绑定和任务目标沿用受控示例。圆点位置使用该示例原有设置，预览、画布和运行保持一致；不为匹配不同历史底图而改业务内容。

## 3. 判定行与角度数值

| 对象 | 常用外观与状态配置 | 原生代码与预期 |
| --- | --- | --- |
| 方向判定，当前“符合” | 背景 `#F0F9F5`，文字／圆点 `#11734C`，基础边框 `1 px solid #72B39C`，圆角 8 px；标题 20 px 粗体，值 16 px 常规；原圆点位置与显隐沿用 | [direction.qss](direction.qss)／[direction.css](direction.css)：左边框 4 px，主值加粗。停用后回到基础 1 px 与常规字重，配色仍来自当前状态配置 |
| 样本分类，当前“复核样本” | 背景 `#FFF7E8`，文字／圆点 `#9B580A`，`2 px solid #D8B57B`，圆角 8 px；标题 20 px／值 16 px，粗体 | 本行使用常用表单即可；保留原文本与状态映射，无需为了重复证明 indicator 再写一套代码 |
| 综合判定，当前“需复核” | 背景 `#FFF2E1`，文字／圆点 `#995305`，`2 px solid #C88A2F`，圆角 8 px；标题 20 px／值 16 px，粗体 | 同上，业务结果仍由已有映射驱动 |
| 角度偏差，样例 `10.0°` | 背景 `#F0F5FC`，`1 px solid #B9CCE4`，圆角 8 px；标题 16 px，主值 52 px、`#214D85`、常规；辅助文字 12 px，文字内容沿用 | [number.qss](number.qss)／[number.css](number.css) 只加粗实际主值；值、精度和单位继续由原绑定与格式化产生 |

在方向判定上短暂把基础边框线型改为本版支持的另一种线型，观察后恢复实线，即可证明线型字段；无需每种控件全测。另用选择器提示对独立 `marker` 做一次可见样式变化，确认不会把主值文字一起当圆点处理，然后恢复目标配色。原生样例的部位名称须在实施时由真实提示核对。

已有状态映射里的其他结果继续使用原配置。验收时触发一次正常结果变化，确认文本／值真实变化，结构化状态配置随之选取；用户自己写的原生规则按约定覆盖关系生效，不增加配色审计逻辑。

## 4. 一次回放证明什么

在每个作者端各完成一次正常链路：原属性入口 → 常用表单和本端代码 → 真实局部预览 → 确定 → 原画布 → 保存重开 → 对应 Qt Runtime／Web 发布页。验证右侧图标、四态、4 px 左边框、实际主值字重和数值卡配色，并保留同一参数记录与截图。

这一次回放可共同满足 A01、A03、A08 和相应基本覆盖条目。其余控件在同一示例工程补基本效果及各自不同的渲染路径，不重复整条链路。字号和几何参数须正确消费，字体抗锯齿与两端原生绘制无需逐像素一致。

实际操作、运行截图及覆盖结果见 [验收记录](../acceptance.md)。
