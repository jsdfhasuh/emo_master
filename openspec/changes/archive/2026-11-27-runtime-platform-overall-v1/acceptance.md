# Runtime 总体验收清单（R3）

本清单对应 Runtime R3，覆盖本期改动和日常操作主链。实际方法、版本、边界与证据见[实施记录](delivery.md)。

## 范围和证据规则

| 类别 | 本期如何处理 |
| --- | --- |
| 【本期必做】 | 必须有对应实际验证结果；可以复用同一相关源码版本的一份证据覆盖多行 |
| 【按实际影响触发】 | 由实际 diff、调用链或可复现问题触发；触发后做定向回归，未触发时说明理由 |
| 【保留约束】 | 沿用已有职责和合同，核对本次变更未破坏；不自动新增实现或完整重验 |

类别与执行结果分开记录：

- `PASS`：实际执行了该行要求的方法，并有对应版本和证据；不扩大解释为其他方法或全产品通过。
- `NOT_RUN`：尚未执行；既不代表通过，也不代表失败。
- `BLOCKED`：需要执行，但被具体条件阻断，记录原因。
- `N/A`：确认不属于本次范围，或影响分析确认触发条件不成立；记录理由，不冒充测试通过。

实施前确认触发项是否适用。既有测试/CI 证据可引用，但必须保留其实际源码版本、执行范围和结果；相关源码发生变化且影响结论时才重跑。计划中引用源码、历史报告、原型或生成文件均不等于产品 PASS。

以下表格是验收映射，不要求每行新增一个测试。可将版本、环境、操作步骤/命令及证据集中记录一次，再在相关行引用。

## I. 完成判定与最小门禁

归档本 Change 必须同时满足：
