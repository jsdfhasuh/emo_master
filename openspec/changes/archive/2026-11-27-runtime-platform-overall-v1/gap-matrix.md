## 影响判定与证据

- “本期必做”形成实际实施与验收要求；已有实现无需重复写，只补确认缺口。
- “按实际影响触发”在实施时根据 diff、直接/传递依赖或可复现问题说明触发原因；复用现有测试，不默认全量运行。
- “保留约束”说明必须维持的产品行为，未受影响时不新增测试前置。引用基线证据写明版本和本轮未重跑，不能写成本轮 PASS。
- P9 汇总可复用证据。同一相关源码版本的一次验证可对应多行，只有相关修改令结果失效时重跑。
- 检查到本期直接缺陷时做局部修复；不要把其他历史问题或未执行项目自动转成阻断。

## 保留的必要边界

Job 真实身份、观察/停止目标分离、owner、设备代次、正常取消、日志有界窗口、固定分页上界、原始值语义、导出范围和工程 QSS 隔离均保留。这些不因精简测试而删除。

## 本包不承诺

- Runtime 核心重写、Web 与 Designer 全功能一致、Runtime MCP 或公网服务。
- 所有 Job 的图像、大对象及未持久化输入输出永久保留。
- 全部 82 算子逐个真实执行、所有故障或分辨率组合、长时压力与节拍专项。
- 冻结包、真实相机/PLC 或生产现场验收通过。
- R1 HTML 原型已完整实现或已通过浏览器交互验证。
