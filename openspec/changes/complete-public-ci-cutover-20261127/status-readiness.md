# Protected private broker: integration contract (not deployed)
The adapter may call terminal only for an unsealed generation. Hash canonical, schema-versioned bytes containing all Binding fields, source event/ref/PR, check and executed SHA, workflow identities, and recipe context, not the SQLite Binding.key() subset. Resolve check versus execution SHA with the product envelope; never infer either from a payload. Obtain the expected generation, attempts, frozen deadline and route pins from the authenticated private ledger. Authenticate the worker run, workflow, release ref, repository, originating actor, run attempt and complete job set via GitHub. Only attest proof=success after the exact recipe's private V2 verification and all required job results; source_failure and watchdog come from independent authenticated stage records, not public claims.

Deploy only after verifying server-enforced no-rewind/no-delete private ledger ref, single trusted status writer, unique lock per (product repository, check SHA, context) spanning read/claim/network-write/readback, immutable worker ref, an independent deadline/retry worker and a monitored private escalation path. No public test process receives the status credential. Reserve the context to this writer: GitHub Commit Status POST has no conditional-write primitive. Do not steal/expire a potentially live writer lock: an abandoned write with uncertain outcome must be fenced before permitting a successor; otherwise fail closed and pause that context. The local ledger transport alone does not prove these conditions.
Persist one terminal decision first, then claim each POST attempt before I/O. Re-read status and generation under lock before retry. An uncertain previous write must be settled before another writer proceeds; if readback remains ambiguous or budget exhausts, escalate, do not post green or silently leave the request active. Preserve the ledger failure; operator reconciles with fresh authenticated readback. Ignore superseded generations, never redispatch a missing receipt. Use readback for sealing, not a 201 alone.
