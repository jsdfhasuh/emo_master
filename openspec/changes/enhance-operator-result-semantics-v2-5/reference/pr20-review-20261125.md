## R1：真实调试身份没有接入详情（高优先级）

Runtime 将可信身份写入 `record.sourceIdentity.operatorId/operatorVersion`，窗口将真实记录交给共享详情；`setDebugResult` 却调用只读取顶层身份的 `_definition(record)`。真实调试记录因此查不到定义，算子中文名称、单位、指标分类与依赖说明提取的生效值缺失。实际执行及原始 JSON/复制不受此问题破坏。

定位：[manager.py:336–345](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/apps/runtime/operator_debug/manager.py#L336-L345)、[窗口:759–763](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/apps/designer/ui/operator_debug_window.py#L759-L763)、[定义匹配:296–303](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/apps/designer/ui/log_record_detail.py#L296-L303)、[调试入口:541–544](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/apps/designer/ui/log_record_detail.py#L541-L544)。

**实际证据：** 通过 build_demo 的当前工程、真实 manager 和 spawned Worker 执行 NumberCompare，输入 0、-1，结果 true。Qt/PySide2 离屏详情的定义查询为 0 次，运行概览和指标来源的本次生效参数未出现，原始 JSON 与复制保留。既有组件测试将调试身份人工放在顶层，所以能通过却没有覆盖真实合同：[测试](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/tests/designer/test_log_json_tree.py#L279-L308)。

**修复与回归：** 从 sourceIdentity 匹配定义并显示身份，保留原始记录及执行归属。用真实 manager 返回结构进入组件，检查说明、适用单位、已有生效证据、身份、原始 JSON/复制。不得向真实记录手工注入顶层身份来使测试通过。沿用正式 Job 与版本不匹配的现有测试，不新建旧日志兼容层。

## R3：动态对象说明没有被共享树读取（中优先级）

Annotate 的 classStyles 通过 additionalProperties 描述动态类别样式。共享树只查 fields/properties/xFieldDescriptions 与数组 items，没有把 additionalProperties 对象说明传给动态成员，导致 displayLabel、color 及颜色通道说明丢失。动态业务 key 本身不需要被翻译或改写。

定位：[共享树:105–113](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/apps/designer/ui/log_record_detail.py#L105-L113)、[实际 Annotate schema:73–105](https://github.com/jsdfhasuh/emo_master/blob/3d6448d3da18790c5f97bfdecb5fc845ebd67a1c/src/emo_master/plugins/builtins/annotate/manifest.json#L73-L105)。

**实际证据：** 使用真实 Annotate schema，在确保定义已匹配的离屏组件中展开 `classStyles → person → displayLabel/color`。外层有中文说明，子字段及颜色元素只显示原 key/索引。这一复现独立于 R1，实际值与复制内容未改变。

**修复与回归：** 固定字段定义优先；未匹配时使用对象形式 additionalProperties，并沿 properties/items 递归解释。布尔形式不是说明，未知字段继续通用显示。用实际 schema 补一个展开场景，同时检查动态 key、对象/数组原值、未知字段与复制内容。只消费已有参数 schema，不扩展端口合同或新增逐算子 UI。
