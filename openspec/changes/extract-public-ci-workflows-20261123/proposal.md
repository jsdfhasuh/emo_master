# 公共合成 CI 验证（仅 GitHub 托管 Runner）

## 背景与本轮决策

用户的长期目标是节省 GitHub Actions 额度，并评估将产品仓库 `emo_master` 转为 Private。安全审查后，用户已将公共端首阶段限定为独立合成项目；2026-11-23 又明确排除私有／自托管 Runner，包括这条路线的设计、费用评估和部署。

本轮审查起点为 PR #21 的 `5f480ded9e4fd162f7e347764581d85d5bee732d`；产品 main 基线为 `b75df0adb7a90a4e0b540ff1c8c09e9339cfcdbd`。仓库接口本轮仍返回 Public。当前 12 个活动工作流和 4 个归档工作流保留在产品仓库，不把目标中的 Private 写成已经发生的状态。

“私有仓库使用 GitHub 托管 Runner”与“自托管 Runner”是不同概念。产品仓库以后即使转为 Private，也可继续使用 GitHub 托管 Runner；本轮不引入用户维护的机器、VM 或 Runner 服务。

## 本轮目标

- 在公开 `jsdfhasuh/emo_master_ci` 中从零建立独立合成 Python 项目，实际验证标准 GitHub 托管 Linux / Windows Runner。
- 验证公共仓库自身触发、Python 环境、测试成功、测试失败的退出码和真实 job 结论。
- 公共端不接收产品源码、产品测试、工程数据、配置、原始诊断、构建产物或产品权限。此约束也适用于当前仍可公开读取的产品内容。
- 保留 `emo_master` 现有产品 CI 的触发、平台、测试集合、断言、报告和检查门禁。
- 给出仅限 GitHub 托管 Runner 的费用口径及后续优化候选，区分已验证事实和尚未实施事项。

## 费用边界

公共仓库使用标准 GitHub 托管 Runner 的计算使用免费；私有仓库使用 GitHub 托管 Runner 消耗账户包含的计算用量，超出部分依账户计费。Reusable Workflow 的计算使用归调用方，单独搬走 YAML 不会改变私有调用方的计费。

本轮没有迁移任何产品测试，因此产品 CI 迁移数为 0，不能报告因公共合成自测节省了产品额度。当前产品仓库本身为 Public，也不能虚构一个已有的私有仓库付费基线。未来 Private 情况只能单列估算，实际费用以账户 Billing / Actions usage 为准。标准计算免费不代表 Larger Runner、存储及外部服务一并免费。

依据见 [design.md](design.md) 的官方资料。

## 实施范围

公共仓库只存放可公开的独立 fixture、测试、自测工作流及说明。可使用公开依赖；不得复制产品源码、历史、样例、测试、诊断或私有依赖。默认使用当前公共仓库作用域的最小只读 `GITHUB_TOKEN`，不配置跨仓库产品凭据，不建立 dispatcher、Source Reader 或产品 Check Run 回调。

产品仓库和公共合成仓库的运行状态分别记录。公共合成成功仅表示基础设施与结果处理可用，不能代替产品测试、产品源码保密验收或闭源准备验收。

## 本轮不实施

- 不评估或部署自托管、自建、本地、租用服务器或所谓“私有 Runner”。
- 不将产品源码送到公共执行环境，不以日志重定向或 Token 撤销作为源码保密保证。
- 不创建产品 GitHub App、产品 Secrets、跨仓库取源权限或产品检查回调。
- 不修改产品工作流，不削减覆盖，不恢复 4 个归档工作流。
- 不合并 PR、不发布产品、不修改 `emo_master` 可见性。

## 完成标准

1. 本变更的最新内容通过 OpenSpec 严格校验和 `git diff --check`，证据对应实际提交／工作区内容。
2. 目标公共仓库及其访问权限已核实；默认分支保护、维护权限和 Actions 权限的实际配置有记录，权限受阻的部分如实列明。
3. Linux / Windows 标准托管 job 各有成功与可控测试失败证据；失败不能被 `continue-on-error`、`|| true` 或汇总逻辑伪装为成功。
4. 公开代码、输入、日志和产物均只涉及独立合成项目；未引入任何产品权限，也未创建或更新产品 required check。
5. 交付公共 workflow / run URL、提交 SHA、平台、job 结论、实际耗时及存储使用说明，明确产品迁移数为 0。
6. 12 个活动产品工作流和 4 个归档工作流保持原状。后续优化与 Private 准备单列，不作为本轮合成验证的隐藏前置任务。

本轮可完成“公共合成 CI 可执行性验证”；“全部产品 CI 迁往公共仓库”仍未获准实施，也未被验证。
