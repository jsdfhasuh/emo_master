# 相机高级属性页待实施计划

- 整理日期：2026-09-10
- 状态：暂缓，独立保存，当前阶段不实施。
- 前置依赖：[camera_live_tuning_plan.md](camera_live_tuning_plan.md) 中的配置会话、实时试调、修改记录、可取消关闭及恢复机制。
- 本文保留原方案的高级属性部分，不代表已有完整属性浏览或写入能力。

## 1. 目标与边界

- 在现有常用属性之外增加“高级属性”页，浏览设备实际公开的其他属性，而不是追加一张写死的参数表。
- 当前像素格式、去马赛克、曝光、增益、帧率、触发和 ROI 等仍归入常用属性，不因增加高级页而挪走或重复提供编辑入口。
- “完整浏览”指设备公开且 SDK 能识别的属性，不承诺所有属性可读、可写或可恢复。
- 不执行相机网络修改、重启、恢复出厂、断电保存、任意命令或原始寄存器写入；软件触发继续使用主计划的受控采集入口。

## 2. 属性发现与能力检查

- 基于本机 IMV SDK 提供的设备描述下载能力构建属性分类，使用 SDK 查询属性类型、有效性、可用性、读写权限和实际值。
- 数值属性查询范围与步长，枚举属性查询设备实际支持的选项；选择器上下文变化后重新查询，不依赖旧缓存。
- XML 仅提供分类、名称、说明和属性关系，不自行执行设备表达式、脚本或外部资源。
- 限制下载、解压及解析范围，拒绝越界路径和异常体积，处理重复引用与分类循环，避免设备描述导致程序失去响应。
- 以已连接设备身份及描述版本隔离缓存，设备切换或描述变化后不能复用错误的属性目录。
- 浏览和刷新本身不得为获取其他通道值而自动写入选择器；明确切换选择器的操作纳入同一试调和恢复记录。
- SDK 不支持、下载失败或解析失败时，仅禁用高级浏览并报告原因，常用配置和采集继续可用。

## 3. 高级页交互

- 提供设备状态、搜索和刷新，左侧为属性分类，右侧为当前属性的说明、实际值、权限、约束及编辑控件。
- 根据类型使用数值输入、枚举下拉框、开关或文本框；只读、不可用、未知类型及禁止写入的属性明确标记。
- 通用界面采用中文；已知属性提供经核对的中文名称，未确认含义的厂商属性保留原始名称与说明，不猜译。
- 显示实际值和待提交输入，数值在回车或失焦时提交，选项和开关选择完成后提交，不在每次键盘输入时写入。
- 加载或刷新表单不触发写入；断连后停止写入并将显示值标记为过期。

## 4. 实时写入与恢复

- 复用主计划的 Runtime 会话和同一个相机 SDK 连接，不由高级页另开连接，也不绕过设备互斥。
- 属性完整浏览，写入采用明确准入清单，默认只读。SDK 返回可写并不能单独证明修改安全或能够恢复。
- 只有经过范围、选择器联动和恢复测试的属性才能开放实时写入；无法读取原值或无法可靠恢复的属性保持只读。
- 原值记录必须包含选择器上下文及关联配置，同值跳过，写前记录意图，写后回读，必要时暂停和恢复采集。
- 高级页与常用页共用同一原始快照和修改账本，切换页签、刷新或重新启动预览不得重置恢复基线。
- 写入失败停止后续操作并报告，不静默回滚；用户关闭时按主计划选择保留、放弃并恢复或继续调整。
- 恢复失败、外部变更、断连和异常退出均复用主计划的处理规则，不承诺整个设备配置原子恢复。

## 5. 项目配置与接口扩展

- 保留相机运行参数不自动保存到项目。用户选择将哪些已验证高级属性加入节点配置。
- 高级配置使用可选列表，记录属性标识、类型、值、选择器上下文和应用顺序；默认空列表，旧项目不要求迁移。
- 常用参数与高级列表去重。同一个设备属性不能存在两套互相覆盖的保存来源。
- 自动工作流连接后，按明确依赖顺序应用保存配置并逐项回读；失败阻止采集，报告已应用项，不宣称整批自动回滚。
- 非当前设备支持的配置必须明确失败或标记不兼容，不静默写到其他同名属性。
- 扩展已有配置会话，增加属性目录和高级属性读写能力；嵌入式与 gRPC 共用实现，不修改算子执行契约。
- 高级属性的风险准入和约束必须在 Runtime 校验，不能仅靠界面置灰保护。

## 6. 实施与验收前提

1. 先完成主计划并通过常用参数的真机试调和恢复验证。
2. 实现只读属性浏览、能力查询和故障降级，核对本机相机实际公开内容。
3. 建立可写属性准入清单及对应恢复测试，逐项开放安全高级属性。
4. 接入高级配置选择保存、重载与工作流应用，验证不会与常用参数冲突。

- 自动化覆盖描述下载和解析边界、分类引用、动态权限、只读和高风险属性拒绝写入，以及界面刷新零写入。
- 验证选择器上下文、范围变化、枚举有效性、关联恢复、回读不一致、结果未知和不支持的设备配置。
- 验证两页共享连接和恢复记录、项目选择保存、旧项目兼容、gRPC 与嵌入式一致性及关闭确认。
- 检查大属性目录的响应、搜索、中文及长属性名称显示、断连过期状态和属性加载失败时常用页可用。
- 真机仅验证能力清单中安全且可恢复的属性，测试前记录原值，测试后恢复并回读；未通过测试的属性保持只读。
- 硬件或 SDK 未验证的能力必须标记限制；不进行网络变更、维护命令、原始寄存器或断电保存验收。

## 7. 当前阶段禁止顺带实施的内容

- 不提前增加高级页、属性树入口或占位编辑功能。
- 不提前接入设备描述下载、XML 解析、任意属性 RPC 或高级配置持久化字段。
- 不因本计划调整当前算子执行规范、改变现场相机配置或修改现有项目数据。
- 后续明确启动高级属性功能时，以该独立计划及届时的 SDK、设备能力复核结果为实施依据。
